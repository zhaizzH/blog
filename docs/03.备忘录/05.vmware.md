# VMware 关闭后台服务

通过批处理文件手动停止或启动 VMware 的后台服务。虚拟机运行期间不要停止这些服务，否则可能影响虚拟机的网络连接、USB 设备使用和相关功能。

## 使用说明

1. 新建一个文本文件，将下面的脚本复制进去。
2. 将文件扩展名从 `.txt` 修改为 `.bat`，例如 `vmware-stop.bat`。
3. 右键批处理文件，选择 **以管理员身份运行**。

> 如果看不到文件扩展名，请先在文件资源管理器的“查看”选项中启用“文件扩展名”。

## 关闭 VMware 服务

在不使用 VMware 时运行下面的脚本，可以释放 VMware 的后台服务占用：

```bat
@echo off

net stop VMwareHostd
net stop VMUSBArbService
net stop VMAuthdService
net stop VMnetDHCP
net stop "VMware NAT Service"

echo VMware 服务已关闭
pause
```

## 开启 VMware 服务

启动虚拟机前运行下面的脚本。否则虚拟机可能无法联网，或无法正常获取 USB 设备：

```bat
@echo off

net start VMAuthdService
net start VMnetDHCP
net start "VMware NAT Service"
net start VMwareHostd
net start VMUSBArbService

echo VMware 服务已开启
pause
```
