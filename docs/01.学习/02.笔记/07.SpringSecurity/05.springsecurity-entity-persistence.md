# Spring Security 数据模型与持久层

Demo-Security 项目采用 ==MyBatis== 作为持久层框架，配合 MySQL 数据库，实现了灵活的多表关联查询。本章详细分析实体设计、Mapper 接口和数据库表结构。

## 数据库表结构

### 表关系图

```
┌───────────────────┐     ┌──────────────────────┐     ┌──────────────────────┐
│       user        │     │      user_role       │     │        role          │
├───────────────────┤     ├──────────────────────┤     ├──────────────────────┤
│ user_id    (PK)   │◄───►│ user_id              │     │ role_id       (PK)   │
│ phone             │     │ role_id              │◄───►│ role_name            │
│ password          │     └──────────────────────┘     └──────────┬───────────┘
│ username          │                                             │
└───────────────────┘                                             │
                                                                  │
                                                    ┌─────────────┴────────────┐
                                                    │                          │
                                                    ▼                          ▼
                                          ┌──────────────────┐     ┌────────────────────────┐
                                          │ role_permission  │     │      permission        │
                                          ├──────────────────┤     ├────────────────────────┤
                                          │ role_id          │◄───►│ permission_id    (PK)  │
                                          │ permission_id    │     │ permission_name        │
                                          └──────────────────┘     └────────────────────────┘
```

### 建表 SQL

```sql
-- 用户表
CREATE TABLE `user` (
    `user_id`   BIGINT PRIMARY KEY AUTO_INCREMENT,
    `phone`     VARCHAR(20)  NOT NULL COMMENT '手机号（登录标识）',
    `password`  VARCHAR(255) NOT NULL COMMENT 'BCrypt 加密密码',
    `username`  VARCHAR(100) DEFAULT NULL COMMENT '用户昵称'
);

-- 角色表
CREATE TABLE `role` (
    `role_id`   BIGINT PRIMARY KEY AUTO_INCREMENT,
    `role_name` VARCHAR(50) NOT NULL COMMENT '角色名称（如 admin）'
);

-- 权限表
CREATE TABLE `permission` (
    `permission_id`   BIGINT PRIMARY KEY AUTO_INCREMENT,
    `permission_name` VARCHAR(100) NOT NULL COMMENT '权限标识（如 user:add）'
);

-- 用户-角色关联表
CREATE TABLE `user_role` (
    `user_id` BIGINT NOT NULL,
    `role_id` BIGINT NOT NULL,
    PRIMARY KEY (`user_id`, `role_id`)
);

-- 角色-权限关联表
CREATE TABLE `role_permission` (
    `role_id`       BIGINT NOT NULL,
    `permission_id` BIGINT NOT NULL,
    PRIMARY KEY (`role_id`, `permission_id`)
);
```

> ==注意：== 关联表 `user_role` 和 `role_permission` 使用复合主键，分别建立外键索引以提高查询性能。

## Mapper 层实现

项目同时使用了 ==注解 SQL== 和 ==XML 映射== 两种方式。

### 注解式 Mapper

```java
@Mapper
public interface UserMapper {

    /**
     * 根据手机号查询用户
     */
    @Select("SELECT * FROM `user` WHERE phone = #{phone}")
    User getUserByPhone(@Param("phone") String phone);
}

@Mapper
public interface UserRoleMapper {

    /**
     * 根据用户 ID 查询用户角色关联
     */
    @Select("SELECT * FROM user_role WHERE user_id = #{userId}")
    List<UserRole> getUserRolesByUserId(@Param("userId") Long userId);
}
```

### XML 映射式 Mapper

```java
@Mapper
public interface RoleMapper {

    /**
     * 批量查询角色（通过角色 ID 集合）
     */
    List<Role> batchGetRolesByRoleIds(@Param("roleIds") List<Long> roleIds);
}

@Mapper
public interface PermissionMapper {

    /**
     * 批量查询权限（通过权限 ID 集合）
     */
    List<Permission> batchGetPermissionsByPermissionIds(
            @Param("permissionIds") List<Long> permissionIds);
}

@Mapper
public interface RolePermissionMapper {

    /**
     * 根据角色 ID 集合查询角色-权限关联
     */
    List<RolePermission> getRolePermissionsByRoleIds(
            @Param("roleIds") List<Long> roleIds);
}
```

### XML 映射文件

```xml
<!-- RoleMapper.xml -->
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper
        PUBLIC "-//mybatis.org//DTD Mapper 3.0//EN"
        "http://mybatis.org/dtd/mybatis-3-mapper.dtd">
<mapper namespace="top.zhaizz.mapper.RoleMapper">

    <select id="batchGetRolesByRoleIds" resultType="top.zhaizz.entity.Role">
        SELECT * FROM role
        WHERE role_id IN
        <foreach collection="roleIds" item="roleId" open="(" separator="," close=")">
            #{roleId}
        </foreach>
    </select>

</mapper>
```

## 完整查询链路

当用户登录时，从手机号到权限的完整数据查询链路如下：

```
用户手机号
    │
    ▼
UserMapper.getUserByPhone(phone)
    │  SELECT * FROM user WHERE phone = #{phone}
    ▼
获取 userId
    │
    ▼
UserRoleMapper.getUserRolesByUserId(userId)
    │  SELECT * FROM user_role WHERE user_id = #{userId}
    ▼
获取 List<roleId>
    │
    ├──▶ RoleMapper.batchGetRolesByRoleIds(roleIds)
    │    │  SELECT * FROM role WHERE role_id IN (...)
    │    ▼
    │   获取 角色名称列表
    │
    └──▶ RolePermissionMapper.getRolePermissionsByRoleIds(roleIds)
         │  SELECT * FROM role_permission WHERE role_id IN (...)
         ▼
         获取 List<permissionId>
              │
              ▼
         PermissionMapper.batchGetPermissionsByPermissionIds(permissionIds)
              │  SELECT * FROM permission WHERE permission_id IN (...)
              ▼
              获取 权限名称列表
```

## MyBatis 配置

```yaml
mybatis:
  # XML 映射文件位置
  mapper-locations: classpath:mapper/*.xml
  # 类型别名包，让 Mapper XML 中可以直接使用类名
  type-aliases-package: top.zhaizz.entity
  configuration:
    # 下划线命名转驼峰命名（如 role_id → roleId）
    map-underscore-to-camel-case: true
```

### 配置说明

| 配置项 | 作用 |
|--------|------|
| `mapper-locations` | 指定 XML 映射文件路径，支持通配符 |
| `type-aliases-package` | 配置实体类的包路径，XML 中可直接使用简单类名 |
| `map-underscore-to-camel-case` | 自动将数据库下划线字段映射为 Java 驼峰属性 |

## 项目入口

```java
@SpringBootApplication
@MapperScan("top.zhaizz.mapper")
public class DemoSecurityApplication {

    public static void main(String[] args) {
        SpringApplication.run(DemoSecurityApplication.class, args);
    }
}
```

> ==注意：== 在主启动类上通过 `@MapperScan` 指定 Mapper 接口的扫描路径，避免在每个 Mapper 接口上重复添加 `@Mapper` 注解（当然也可以两者任选其一）。
