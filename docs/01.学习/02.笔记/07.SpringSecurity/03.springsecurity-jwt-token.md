# Spring Security JWT 与 Token 认证

JWT（JSON Web Token）是一种基于 Token 的认证方案。在 Demo-Security 项目中，JWT 作为 ==Redis 中用户会话的 Key==，实现了无状态、可扩展的认证机制。

## JWT 工具类

项目使用 `com.auth0.java-jwt` 库进行 JWT 的生成和验证：

```java
@Component
public class JwtUtils {

    /**
     * HMAC256 密钥
     */
    private static final String SECRET = "YLWTSMTJFYHDCMGSCWHSSYBZSDKC";

    /**
     * 生成 JWT
     *
     * @param pub         签发人（存储用户手机号）
     * @param expiresTime 过期时间（毫秒）
     * @return JWT 字符串
     */
    public String sign(String pub, Long expiresTime) {
        return JWT.create()
                .withIssuer(pub)
                .withExpiresAt(new Date(System.currentTimeMillis() + expiresTime))
                .sign(Algorithm.HMAC256(SECRET));
    }

    /**
     * 验证 JWT 是否有效
     */
    public boolean verify(String token) {
        try {
            JWT.require(Algorithm.HMAC256(SECRET)).build().verify(token);
            return true;
        } catch (Exception e) {
            return false;
        }
    }

    /**
     * 获取 JWT 中的签发人（手机号）
     */
    public String getClaim(String token) {
        return JWT.require(Algorithm.HMAC256(SECRET))
                .build()
                .verify(token)
                .getIssuer();
    }
}
```

### JWT 结构解析

一个 JWT 由三部分组成，用 `.` 分隔：

```
header.payload.signature
```

| 部分 | 说明 | 示例 |
|------|------|------|
| **Header** | 令牌类型和签名算法 | `{"alg":"HS256","typ":"JWT"}` |
| **Payload** | 数据声明（issuer、过期时间等） | `{"iss":"138xxxx","exp":...}` |
| **Signature** | 签名，用于验证完整性 | 使用 HMAC256 + 密钥生成 |

> ==注意：== JWT 的 Payload 是 Base64 编码，并非加密。敏感信息不应直接存储在 JWT 中。本项目将用户数据存储在 Redis，JWT 仅作为 key，这是更安全的做法。

## Token 认证过滤器

`JwtAuthenticationTokenFilter` 是 Spring Security 过滤器链中的核心组件，==每次请求都会经过此过滤器==进行 Token 校验：

```java
@Component
public class JwtAuthenticationTokenFilter extends OncePerRequestFilter {

    @Resource
    private JwtUtils jwtUtils;
    @Resource
    private RedisClient redisClient;

    @Override
    protected void doFilterInternal(HttpServletRequest request,
                                    HttpServletResponse response,
                                    FilterChain filterChain)
            throws ServletException, IOException {

        // 1. 从请求头获取 token
        String token = request.getHeader("token");

        // 2. 如果 token 不存在，直接放行（后续 SecurityConfig 会判断是否需要认证）
        if (StringUtils.hasText(token)) {

            // 3. 从 Redis 获取用户信息
            //    key 格式：login:token:{jwt}
            String userJson = redisClient.get("login:token:" + token);

            if (StringUtils.hasText(userJson)) {
                // 4. 将 JSON 反序列化为 LoginUserDetails
                LoginUserDetails loginUserDetails =
                        JSONUtil.toBean(userJson, LoginUserDetails.class);

                // 5. 创建已认证的 UsernamePasswordAuthenticationToken
                UsernamePasswordAuthenticationToken authenticationToken =
                        new UsernamePasswordAuthenticationToken(
                                loginUserDetails, null,
                                loginUserDetails.getAuthorities());

                // 6. 存入 SecurityContextHolder
                SecurityContextHolder.getContext()
                        .setAuthentication(authenticationToken);
            }
        }

        // 7. 放行请求
        filterChain.doFilter(request, response);
    }
}
```

### 过滤器注册

在 `SecurityConfig` 中，通过 `addFilterBefore` 将自定义过滤器注册到 `UsernamePasswordAuthenticationFilter` 之前：

```java
httpSecurity
    .addFilterBefore(jwtAuthenticationTokenFilter,
                     UsernamePasswordAuthenticationFilter.class);
```

### 过滤流程

```
请求进入
    │
    ▼
JwtAuthenticationTokenFilter
    │
    ├── 是否有 token 头？──── 否 ──▶ 放行
    │
    ▼ 是
    │
    ├── Redis 中是否存在？──── 否 ──▶ 放行（后续由 Security 判定）
    │
    ▼ 是
    │
    ├── 反序列化 LoginUserDetails
    │
    ├── 创建 UsernamePasswordAuthenticationToken
    │
    ├── 设置 SecurityContextHolder
    │
    ▼
放行，进入后续过滤器
```

## Redis 缓存

### Redis 工具类

```java
@Component
public class RedisClient {

    @Resource
    private StringRedisTemplate stringRedisTemplate;

    public void set(String key, String value, long timeout) {
        stringRedisTemplate.opsForValue()
                .set(key, value, timeout, TimeUnit.SECONDS);
    }

    public String get(String key) {
        return stringRedisTemplate.opsForValue().get(key);
    }

    public void del(String key) {
        stringRedisTemplate.opsForValue().getOperations().delete(key);
    }

    public Boolean exists(String key) {
        return stringRedisTemplate.hasKey(key);
    }
}
```

### 缓存策略

| 场景 | 操作 | Key 格式 |
|------|------|----------|
| 登录成功 | 写入缓存 | `login:token:{jwt}` |
| 请求认证 | 读取缓存 | `login:token:{jwt}` |
| 注销 | 删除缓存 | `login:token:{jwt}` |
| 重新登录 | 覆盖旧缓存 | `login:token:{newJwt}` |

### TTL 设置

- **JWT 过期时间**：7 天（`1000 * 60 * 60 * 24 * 7L` 毫秒）
- **Redis TTL**：与 JWT 过期时间一致，单位转换为秒

## 注销流程

注销功能通过 `LogoutStatusSuccessHandler` 实现：

```java
@Component
public class LogoutStatusSuccessHandler implements LogoutSuccessHandler {

    @Resource
    private RedisClient redisClient;

    @Override
    public void onLogoutSuccess(HttpServletRequest request,
                                HttpServletResponse response,
                                Authentication authentication)
            throws IOException {

        // 1. 获取请求头中的 token
        String token = request.getHeader("token");

        // 2. 删除 Redis 中的用户缓存
        if (StringUtils.hasText(token)) {
            redisClient.del("login:token:" + token);
        }

        // 3. 返回注销成功响应
        response.setContentType("application/json;charset=utf-8");
        response.getWriter().write(
                JSONUtil.toJsonStr(new Result(200, "注销成功", null)));
    }
}
```

注销端点在 Security 配置中放行，无需认证即可访问：

```java
httpSecurity
    .logout(logout -> logout
            .logoutUrl("/logout")
            .logoutSuccessHandler(logoutStatusSuccessHandler));
```

> ==注意：== `/logout` 虽然无需认证即可访问，但只有携带有效 Token 的请求才会真正执行 Redis 清理操作。这是一种"无害放行"的设计。

## 单设备登录

项目实现了一种简单的 ==单设备登录== 机制。在 `LoginService` 中，登录前会检查请求头中是否携带 Token：

```java
// 如果请求头携带了 token，且 JWT 中的 issuer 与当前手机号匹配，
// 则清除旧会话，实现同一账号只允许一处登录
String token = request.getHeader("token");
if (StringUtils.hasText(token)) {
    try {
        String claim = jwtUtils.getClaim(token);
        if (phone.equals(claim)) {
            redisClient.del("login:token:" + token);
        }
    } catch (Exception ignored) {}
}
```

## 无状态会话

项目使用 `SessionCreationPolicy.STATELESS` 策略，完全基于 Token 进行认证：

```java
httpSecurity
    .sessionManagement(session -> session
            .sessionCreationPolicy(SessionCreationPolicy.STATELESS));
```

### 无状态认证的优势

| 特性 | 说明 |
|------|------|
| **扩展性** | 服务器不存储会话，便于水平扩展 |
| **跨域** | Token 可以在不同域之间传递 |
| **去中心化** | 不依赖特定的服务器节点 |
| **即时失效** | 删除 Redis Key 即可立即使会话失效 |
