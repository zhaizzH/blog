# Spring Security 认证流程

认证（Authentication）是身份验证的过程，即系统确认"你是谁"。Demo-Security 项目采用 ==手机号 + 密码== 的认证方式，整合 Spring Security 的 `AuthenticationManager` 体系，配合 JWT 实现无状态认证。

## 认证核心组件

### AuthenticationManager

`AuthenticationManager` 是 Spring Security 认证的顶层接口，定义了 `authenticate()` 方法。项目的配置类中将其声明为 Bean：

```java
@Configuration
@EnableMethodSecurity(securedEnabled = true)
public class SecurityConfig {

    @Bean
    public PasswordEncoder generalPasswordEncoder() {
        return new BCryptPasswordEncoder();
    }

    @Bean
    public AuthenticationManager authenticationManager(
            AuthenticationConfiguration authenticationConfiguration) throws Exception {
        return authenticationConfiguration.getAuthenticationManager();
    }

    // ... 其他配置
}
```

### UserDetailsService 实现

自定义的 `UserDetailsServiceImpl` 实现了 `UserDetailsService` 接口，负责从数据库加载用户信息：

```java
@Component
public class UserDetailsServiceImpl implements UserDetailsService {

    @Resource
    private UserMapper userMapper;
    @Resource
    private UserRoleMapper userRoleMapper;
    @Resource
    private RoleMapper roleMapper;
    @Resource
    private RolePermissionMapper rolePermissionMapper;
    @Resource
    private PermissionMapper permissionMapper;

    @Override
    public LoginUserDetails loadUserByUsername(String phone) throws UsernameNotFoundException {
        // 1. 根据手机号查询用户
        User user = userMapper.getUserByPhone(phone);
        if (Objects.isNull(user)) {
            return null;
        }

        // 2. 查询用户角色 ID
        List<UserRole> userRoles = userRoleMapper.getUserRolesByUserId(user.getUserId());
        List<Long> roleIds = userRoles.stream().map(UserRole::getRoleId).toList();

        // 3. 批量查询角色名称
        List<Role> roles = roleMapper.batchGetRolesByRoleIds(roleIds);
        List<String> roleNames = roles.stream().map(Role::getRoleName).toList();

        // 4. 查询角色对应的权限 ID
        List<RolePermission> rolePermissions =
                rolePermissionMapper.getRolePermissionsByRoleIds(roleIds);
        List<Long> permissionIds = rolePermissions.stream()
                .map(RolePermission::getPermissionId).toList();

        // 5. 批量查询权限名称
        List<Permission> permissions =
                permissionMapper.batchGetPermissionsByPermissionIds(permissionIds);
        List<String> permissionNames = permissions.stream()
                .map(Permission::getPermissionName).toList();

        // 6. 封装并返回 LoginUserDetails
        return new LoginUserDetails(user, roleNames, permissionNames);
    }
}
```

### LoginUserDetails

`LoginUserDetails` 实现了 `UserDetails` 接口，是 Spring Security 的用户信息载体：

```java
@Data
@NoArgsConstructor
@AllArgsConstructor
public class LoginUserDetails implements UserDetails {

    private User user;
    private List<String> roleNames;
    private List<String> permissionNames;

    @Override
    public Collection<? extends GrantedAuthority> getAuthorities() {
        List<GrantedAuthority> authorities = new ArrayList<>();

        // 角色权限 —— Spring Security 要求角色以 "ROLE_" 为前缀
        for (String roleName : roleNames) {
            authorities.add(new SimpleGrantedAuthority("ROLE_" + roleName));
        }

        // 权限标识 —— 直接使用权限名
        for (String permissionName : permissionNames) {
            authorities.add(new SimpleGrantedAuthority(permissionName));
        }
        return authorities;
    }

    @Override
    public String getPassword() {
        return user.getPassword();
    }

    @Override
    public String getUsername() {
        return user.getUsername();
    }

    @Override
    public boolean isAccountNonExpired() { return true; }

    @Override
    public boolean isAccountNonLocked() { return true; }

    @Override
    public boolean isCredentialsNonExpired() { return true; }

    @Override
    public boolean isEnabled() { return true; }
}
```

> ==注意：== `getAuthorities()` 方法中，角色名称需要添加 `ROLE_` 前缀，这样 `hasRole('admin')` 表达式才能正确匹配。而权限名称则保持原样，供 `hasAuthority('user:add')` 使用。

## 登录流程

### 登录入口

```java
@RestController
public class LoginController {

    @Resource
    private LoginService loginService;

    @PostMapping("/login")
    public Result login(@RequestParam("phone") String phone,
                        @RequestParam("password") String password) {
        return loginService.login(phone, password);
    }
}
```

### 登录服务

`LoginService` 是认证的核心业务逻辑所在：

```java
@Service
public class LoginService {

    @Resource
    private AuthenticationManager authenticationManager;
    @Resource
    private RedisClient redisClient;
    @Resource
    private JwtUtils jwtUtils;

    /**
     * 用户登录
     *
     * @param phone    手机号
     * @param password 密码
     * @return 登录结果，包含 token
     */
    public Result login(String phone, String password) {
        // 1. 创建 UsernamePasswordAuthenticationToken
        UsernamePasswordAuthenticationToken token =
                new UsernamePasswordAuthenticationToken(phone, password);

        try {
            // 2. 调用 AuthenticationManager 进行认证
            Authentication authenticate = authenticationManager.authenticate(token);

            // 3. 认证成功，生成 JWT
            LoginUserDetails loginUserDetails =
                    (LoginUserDetails) authenticate.getPrincipal();

            // 设置 token 过期时间为 7 天
            long expiresTime = 1000 * 60 * 60 * 24 * 7L;
            String jwt = jwtUtils.sign(loginUserDetails.getUser().getPhone(), expiresTime);

            // 4. 将用户信息存入 Redis，key 为 "login:token:{jwt}"
            redisClient.set("login:token:" + jwt,
                    JSONUtil.toJsonStr(loginUserDetails), expiresTime / 1000);

            // 5. 返回 token
            Map<String, String> map = new HashMap<>();
            map.put("token", jwt);
            return new Result(200, "登录成功", map);

        } catch (Exception e) {
            e.printStackTrace();
            return new Result(500, "认证失败,用户名或密码错误", null);
        }
    }
}
```

### 认证时序

| 步骤 | 发起方 | 组件 | 动作描述 |
|:----:|:------:|------|----------|
| ① | 客户端 | `POST /login` | 向服务器发送手机号和密码 |
| ② | 服务器 | `LoginService.login()` | 创建 `UsernamePasswordAuthenticationToken(phone, password)` |
| ③ | 服务器 | `AuthenticationManager.authenticate()` | 调用认证管理器进行认证 |
| ④ | 服务器 | `UserDetailsServiceImpl` | 委托 UserDetailsService 从数据库加载用户、角色和权限信息 |
| ⑤ | 服务器 | `BCryptPasswordEncoder` | 密码校验（比对加密后的密文） |
| ⑥ | 服务器 | `AuthenticationManager` | 认证成功，返回已认证的 Authentication 对象 |
| ⑦ | 服务器 | `JwtUtils.sign()` | 生成 JWT Token（HMAC256，过期时间 7 天） |
| ⑧ | 服务器 | `RedisClient.set()` | 将用户信息缓存到 Redis，Key 为 `login:token:{jwt}` |
| ⑨ | 服务器 | `LoginService` | 返回 `{token: "xxx.jwt"}` 给客户端 |
| ⑩ | 客户端 | — | 收到 Token，后续请求在请求头中携带 `token` 字段 |

## 密码加密

项目使用 ==BCrypt 密码编码器==，它是 Spring Security 推荐的密码加密方案：

```java
@Bean
public PasswordEncoder generalPasswordEncoder() {
    return new BCryptPasswordEncoder();
}
```

BCrypt 的特点：

- **加盐处理**：自动生成随机盐值，相同的密码加密后结果不同
- **不可逆**：哈希算法，无法从密文解密出明文
- **自适应**：可以通过调整强度参数来增加计算成本，抵御暴力破解

> ==注意：== 数据库中的密码字段应存储 BCrypt 加密后的密文，而非明文。在测试类中可以通过 `BCryptPasswordEncoder` 生成密码：
>
> ```java
> @Test
> void testPassword() {
>     BCryptPasswordEncoder encoder = new BCryptPasswordEncoder();
>     String encoded = encoder.encode("123456");
>     System.out.println(encoded);
>     // 输出示例：$2a$10$N9qo8uLOickgx2ZMRZoMyeIjZAgcfl7p92ldGxad68LJZdL17lhWy
> }
> ```

## 认证入口与异常处理

### 未认证访问处理

当用户未登录或 Token 过期时访问需要认证的资源，由 `AuthenticationEntryPoint` 处理：

```java
@Component
public class LoginUnAuthenticationEntryPointHandler implements AuthenticationEntryPoint {

    @Override
    public void commence(HttpServletRequest request, HttpServletResponse response,
                         AuthenticationException authException) throws IOException {
        response.setContentType("application/json;charset=utf-8");
        response.getWriter().write(JSONUtil.toJsonStr(
                new Result(-1, "用户未认证或登录已过期，请重新登录后再访问", null)));
    }
}
```
