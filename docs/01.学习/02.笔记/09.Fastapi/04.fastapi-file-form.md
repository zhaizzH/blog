# FastAPI 表单与文件上传

> HTML 表单走的是另一套编码，不是 JSON：`Form` 收普通字段、`File` 收文件，两者混着声明也没问题，还能把表单字段整个塞进 Pydantic 模型统一校验。前提是先装 `python-multipart`。

## 一、表单数据

### 1.1 先装依赖

用 `Form` 之前必须装 `python-multipart`，它是解析表单编码的底层库：

```console
$ pip install python-multipart
```

不装的话，一启动就报错，FastAPI 会提示缺少这个包。

### 1.2 用 Form 声明参数

最典型的场景是登录接口。OAuth2 的「密码流」规范要求 `username` 和 `password` 必须以表单字段发送，而不是 JSON：

```python
from typing import Annotated

from fastapi import FastAPI, Form

app = FastAPI()

@app.post("/login/")
async def login(username: Annotated[str, Form()], password: Annotated[str, Form()]):
    return {"username": username}
```

和 `Body` / `Query` 完全同一个套路：参数类型 + 默认值方式，`Form()` 声明数据来源是表单。`Form` 支持 `Query` / `Path` / `Cookie` 那套全部配置——校验规则、示例、别名（比如把 `username` 对外写成 `user-name`）都能配。前端对应的提交方式：

```html
<form action="/login/" method="post">
    <input type="text" name="username" />
    <input type="password" name="password" />
    <button type="submit">登录</button>
</form>
```

表单字段的 `name` 要和参数名对得上。

::: info 提示
`Form` 其实是 `Body` 的子类，所以它天然继承请求体参数的所有能力。但注意：**必须显式写 `Form()`**。不写的话，FastAPI 分不清这个参数该从哪取，会默认当成查询参数或 JSON 请求体，接口行为就完全不对了。
:::

### 1.3 表单到底是怎么编码的

表单提交走另一套编码，不是 JSON：

- 普通表单（无文件）：`application/x-www-form-urlencoded`，形如 `username=john&password=secret`
- 带文件的表单：媒体类型 `multipart/form-data`（第三章讲）

FastAPI 按请求头媒体类型自动解析，不用手动处理。

### 1.4 Form 和 Body 不能混用

一个路径操作里可以声明多个 `Form` 参数，但**不能**同时声明收 JSON 的 `Body` 字段：

```python
# 会出问题：一个请求体不可能既是 urlencoded 又是 JSON
@app.post("/mixed/")
async def mixed(a: Annotated[str, Form()], b: Annotated[dict, Body()]):
    ...
```

原因在 HTTP 协议本身：一个请求体只能有一种媒体类型。声明了 `Form`，请求体就是 `application/x-www-form-urlencoded`，没法再同时按 `application/json` 解析。要收 JSON 就用 `Body`，要收表单就用 `Form`，二选一。

| 场景 | 用什么 | 媒体类型 |
| ---- | ---- | ---- |
| JSON 请求体 | `Body`（或直接模型） | `application/json` |
| 普通表单 | `Form` | `application/x-www-form-urlencoded` |
| 带文件的表单 | `File`（第三章） | `multipart/form-data` |

## 二、表单模型

### 2.1 表单也能用 Pydantic 模型

JSON 请求体可以直接声明成 Pydantic 模型，表单数据其实也行。先建一个模型，字段就是希望接收的表单字段，然后参数类型写模型、默认值写 `Form()`：

```python
from typing import Annotated

from fastapi import FastAPI, Form
from pydantic import BaseModel

app = FastAPI()

class FormData(BaseModel):
    username: str
    password: str

@app.post("/login/")
async def login(data: Annotated[FormData, Form()]):
    return data
```

`FormData` 里每个字段，FastAPI 都会从请求的表单数据里**逐个提取**，组装成模型实例传给函数。前端还是普通的表单提交，字段名和模型字段名对得上就行。打开 `/docs`，Swagger UI 里能看到这个接口接收 `username`、`password` 两个表单字段，和手写两个 `Form()` 参数效果一致，但代码清爽多了——字段多了以后，模型还能复用。

::: info 提示
这个功能要求 FastAPI `0.113.0+`，太老的版本会直接报错。另外和普通表单一样，得先 `pip install python-multipart`。
:::

### 2.2 禁止额外的表单字段

默认情况下，客户端多传几个没声明的字段，FastAPI 会直接忽略。想严格一点——只允许模型里声明过的字段，多一个都不行——给模型加配置：

```python
class FormData(BaseModel):
    username: str
    password: str
    model_config = {"extra": "forbid"}
```

关键就一行：`model_config = {"extra": "forbid"}`。这是 Pydantic 的模型配置，不只是表单模型能用，JSON 模型同样适用。现在客户端如果多传一个 `extra` 字段，响应直接报错：

```json
{
    "detail": [
        {
            "type": "extra_forbidden",
            "loc": ["body", "extra"],
            "msg": "Extra inputs are not permitted",
            "input": "Mr. Poopybutthole"
        }
    ]
}
```

`loc` 里点名了 `extra` 这个字段不被允许。注意 `loc` 显示的是 `body`，因为表单数据在 FastAPI 眼里就是请求体的一部分。

::: info 提示
`extra: "forbid"` 是 `0.114.0+` 才支持的。用不用看场景：公开接口建议开，防止客户端瞎传字段；内部接口默认忽略就行，别为了「严格」误伤正常调用。
:::

### 2.3 和手写多个 Form 参数怎么选

| 方式 | 写法 | 适合场景 |
| ---- | ---- | ---- |
| 多个 `Form()` 参数 | 每个字段一个参数 | 字段少（两三个）、不复用 |
| 表单模型 | 一个模型参数 | 字段多、多个接口共用同一组字段、要统一校验规则 |

模型方式的好处：多个接口共用同一组字段时，校验规则集中在模型里，改一处全生效。

## 三、文件上传

### 3.1 先装依赖

文件上传走 `multipart/form-data` 编码，解析靠的还是 `python-multipart`，不装一用 `File` 就启动报错。

### 3.2 bytes 还是 UploadFile

两种声明方式：

```python
from typing import Annotated

from fastapi import FastAPI, File, UploadFile

app = FastAPI()

@app.post("/files/")
async def create_file(file: Annotated[bytes, File()]):
    return {"file_size": len(file)}

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile):
    return {"filename": file.filename}
```

| 方式 | 声明 | 特点 |
| ---- | ---- | ---- |
| `bytes` | `file: Annotated[bytes, File()]` | 读完整文件放内存，适合小文件 |
| `UploadFile` | `file: UploadFile` | spooled：先存内存，超上限落盘，适合大文件 |

注意 `UploadFile` 不用写 `File()` 默认值。`File` 是 `Form` 的子类，**必须显式写**，不然会被当成查询参数或 JSON 请求体。

`UploadFile` 的属性：`filename`（原始文件名）、`content_type`（MIME 类型）、`file`（底层 `SpooledTemporaryFile`，file-like 对象，可直接传给其他库）。方法都是 `async` 的，要 `await`：

```python
contents = await myfile.read()      # 读全部内容
await myfile.write(b"data")         # 写数据
await myfile.seek(0)                # 回到开头
await myfile.close()                # 关闭
```

普通 `def` 接口（非 `async`）直接操作底层对象：`contents = myfile.file.read()`。

::: info 提示
`async` 方法内部把同步文件方法丢线程池跑。`UploadFile` 继承自 Starlette，FastAPI 做了调整使其兼容 Pydantic。
:::

### 3.3 可选文件上传

文件非必传时，类型标 `| None`、默认值 `None`：

```python
@app.post("/files/")
async def create_file(file: Annotated[bytes | None, File()] = None):
    if not file:
        return {"message": "No file sent"}
    return {"file_size": len(file)}

@app.post("/uploadfile/")
async def create_upload_file(file: UploadFile | None = None):
    if not file:
        return {"message": "No upload file sent"}
    return {"filename": file.filename}
```

`UploadFile` 也能配 `File()`，比如写描述，文档里会显示：

```python
@app.post("/uploadfile/")
async def create_upload_file(
    file: Annotated[UploadFile, File(description="A file read as UploadFile")],
):
    return {"filename": file.filename}
```

### 3.4 一次传多个文件

类型写成 `list[bytes]` 或 `list[UploadFile]`，返回也是列表：

```python
@app.post("/files/")
async def create_files(files: Annotated[list[bytes], File()]):
    return {"file_sizes": [len(file) for file in files]}

@app.post("/uploadfiles/")
async def create_upload_files(files: list[UploadFile]):
    return {"filenames": [file.filename for file in files]}
```

前端表单多个文件共用一个字段名（`<input name="files" type="file" multiple>`）。列表也能加元数据：`File(description="...")`。

::: info 提示
一个接口能混用多个 `File` / `Form` 参数，但**不能**再声明收 JSON 的 `Body` 字段——请求体已是 `multipart/form-data`，这是 HTTP 协议的规定，不是 FastAPI 的毛病。
:::

## 四、表单与文件混合

### 4.1 File 和 Form 一起用

典型的场景：上传文件的同时带一个 token 做身份校验。两个 `File` 加一个 `Form` 混在同一个接口里：

```python
from typing import Annotated

from fastapi import FastAPI, File, Form, UploadFile

app = FastAPI()

@app.post("/files/")
async def create_file(
    file: Annotated[bytes, File()],
    fileb: Annotated[UploadFile, File()],
    token: Annotated[str, Form()],
):
    return {
        "file_size": len(file),
        "token": token,
        "fileb_content_type": fileb.content_type,
    }
```

声明方式和 `Body` / `Query` 同一套套路，没有任何新语法：

- `file`：收成 `bytes`，整个读进内存
- `fileb`：收成 `UploadFile`，走 spooled 缓存，适合大文件
- `token`：普通表单字段，用 `Form()` 声明

一个接口里 `bytes` 和 `UploadFile` 可以混着用，按需选。前端提交时，文件字段和普通字段都放在同一个表单里，`enctype="multipart/form-data"`：

```html
<form action="/files/" enctype="multipart/form-data" method="post">
    <input type="file" name="file" />
    <input type="file" name="fileb" />
    <input type="text" name="token" />
    <input type="submit" />
</form>
```

### 4.2 为什么必须带 Form()

`token` 这种普通字段，如果忘了写 `Form()`，FastAPI 就不知道它该从哪取：

| 声明 | FastAPI 的解读 |
| ---- | ---- |
| `token: Annotated[str, Form()]` | 从表单数据取 |
| `token: str` | 当成查询参数（`?token=xxx`） |
| `token: str = Body()` | 要 JSON 请求体 |

忘了写 `Form()`，接口行为就完全变了——客户端按表单提交，服务端却在等查询参数，联调半天发现 token 一直是空。这个坑在第一章踩过一次，混用时要格外注意。

### 4.4 小结

- `File` 收文件、`Form` 收普通字段，混着声明没问题
- `bytes` 适合小文件，`UploadFile` 适合大文件，可混用
- 普通字段不写 `Form()` 会被当成查询参数，白调半天
- `File` / `Form` 和 `Body` 水火不容，一个接口只能选一边
- 表单字段多、要复用时优先用 Pydantic 表单模型，校验规则集中管理
