# FastAPI 进阶功能

> 中间件、CORS、后台任务、多文件路由、测试调试 — 把单个接口的 FastAPI 撑成能上线的项目。

## 一、中间件

中间件是夹在请求和路径操作之间的函数：每个请求进来先过它，每个响应出去再过它。

```python
import time
from fastapi import FastAPI, Request

app = FastAPI()

@app.middleware("http")
async def add_process_time_header(request: Request, call_next):
    start = time.perf_counter()
    response = await call_next(request)   # 交给路径操作处理
    process_time = time.perf_counter() - start
    response.headers["X-Process-Time"] = str(process_time)
    return response
```

`call_next` 把请求往下传，返回路径操作生成的响应。想在响应上做手脚（加 header、改内容）就在它后面改。

### 1.1 多个中间件的执行顺序

多个中间件是**栈**结构，后添加的在最外层：

```python
app.add_middleware(MiddlewareA)
app.add_middleware(MiddlewareB)
```

- 请求：`MiddlewareB → MiddlewareA → 路由`
- 响应：`路由 → MiddlewareA → MiddlewareB`

最后添加的中间件最先处理请求、最后处理响应。

## 二、CORS 跨域

浏览器里跑的前端（如 `http://localhost:8080`）去调不同源的接口（如 `http://localhost:8000`），会触发跨域限制。源 = 协议 + 域名 + 端口，三者任一不同就算跨域。

后端需要声明"允许哪些源"：

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:8080"],   # 允许的源，开发期可用 ["*"]
    allow_credentials=True,                     # 允许 Cookie / Authorization 头
    allow_methods=["*"],                        # 允许的请求方法
    allow_headers=["*"],                        # 允许的请求头
)
```

| 参数 | 作用 |
| ---- | ---- |
| `allow_origins` | 允许的源列表，`["*"]` 全放行 |
| `allow_origin_regex` | 正则匹配源 |
| `allow_credentials` | 是否允许携带凭证（Cookie、Bearer 令牌） |
| `allow_methods` | 允许的方法，如 `["GET", "POST"]` |
| `allow_headers` | 允许的请求头 |
| `expose_headers` | 浏览器可见的响应头 |

::: info 提示
`"*"` 通配符不允许携带凭证的请求。要带 Cookie 或 Authorization 头，必须显式列源。
:::

## 三、后台任务

响应返回**之后**再执行的任务，适合发邮件、处理大文件这类慢操作 — 客户端不用干等：

```python
from fastapi import FastAPI, BackgroundTasks

app = FastAPI()

def write_notification(email: str, message: str = ""):
    with open("log.txt", "w") as f:
        f.write(f"notification for {email}: {message}")

@app.post("/send-notification/{email}")
async def send_notification(email: str, background_tasks: BackgroundTasks):
    background_tasks.add_task(write_notification, email, message="some notification")
    return {"message": "Notification sent in the background"}
```

- 任务函数普通 `def` 或 `async def` 都行
- `add_task(func, *args, **kwargs)` 传参数
- 后台任务也能在依赖里声明，全部合并后一起执行

重型后台计算（跨进程、跨服务器）就别用这个，上 Celery + Redis 那套。

## 四、APIRouter：拆成多文件

项目大了不可能全写在一个 `main.py` 里。`APIRouter` 相当于 Flask 的 Blueprint，按模块拆路由：

```python
# app/routers/users.py
from fastapi import APIRouter

router = APIRouter()

@router.get("/users/")
async def read_users():
    return [{"username": "Rick"}, {"username": "Morty"}]
```

```python
# app/main.py
from fastapi import FastAPI
from app.routers import users

app = FastAPI()
app.include_router(users.router)
```

推荐结构：

```
app/
├── __init__.py          # 让 app 成为 Python 包
├── main.py              # 创建 FastAPI 实例，include_router
├── dependencies.py      # 共享依赖
├── routers/             # 各模块路由
│   ├── __init__.py
│   ├── items.py
│   └── users.py
└── internal/            # 内部工具
    └── admin.py
```

每个目录都要有 `__init__.py`，否则不能跨文件 import。

## 五、静态文件

挂载一个目录，直接对外提供静态资源（图片、CSS）：

```python
from fastapi.staticfiles import StaticFiles

app.mount("/static", StaticFiles(directory="static"), name="static")
```

`/static` 开头的请求全部由这个"子应用"处理。注意 `mount` 是挂载独立应用，主应用的 OpenAPI 文档里**不会**包含它。

## 六、元数据：API 标题与描述

`FastAPI()` 构造时传入，文档页（`/docs`）会显示：

```python
app = FastAPI(
    title="我的 API",
    description="这是一个**示例** API，支持 Markdown。",
    version="2.5.0",
    terms_of_service="http://example.com/terms/",
    contact={"name": "zhaizz", "email": "zhaizzh@qq.com"},
    license_info={"name": "MIT"},
)
```

| 参数 | 说明 |
| ---- | ---- |
| `title` | API 标题 |
| `description` | 描述，支持 Markdown |
| `version` | 应用版本号 |
| `terms_of_service` / `contact` / `license_info` | 服务条款、联系、许可证信息 |

标签分组也能配元数据：`openapi_tags` 传列表，每项是 `{"name": "users", "description": "用户相关接口"}`，文档里按标签分组显示。

## 七、测试

FastAPI 自带 TestClient（基于 httpx），配 pytest 直接测接口：

```bash
pip install httpx pytest
```

```python
from fastapi.testclient import TestClient
from main import app

client = TestClient(app)

def test_read_main():
    response = client.get("/")
    assert response.status_code == 200
    assert response.json() == {"message": "Hello World"}
```

- 测试函数是普通 `def`，调用也是同步的，pytest 直接跑
- 放单独文件 `test_main.py`，`from main import app` 导入
- 测试里也能覆盖登录、鉴权、依赖注入的场景

## 八、调试

开发期直接在代码里跑 uvicorn，方便接 IDE 调试器：

```python
import uvicorn

if __name__ == "__main__":
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

```bash
python main.py
```

`if __name__ == "__main__"` 保证只有直接运行这个文件时才启动服务器 — 被其他文件 `import` 时不会意外起服务。这样 VSCode/PyCharm 的调试器能直接断点进 FastAPI 代码。

## 九、小结

| 功能 | 入口 |
| ---- | ---- |
| 请求/响应钩子 | `@app.middleware("http")` |
| 跨域 | `CORSMiddleware` |
| 响应后执行 | `BackgroundTasks.add_task()` |
| 多文件路由 | `APIRouter` + `include_router` |
| 静态资源 | `app.mount("/static", StaticFiles(...))` |
| 文档元数据 | `FastAPI(title=..., description=...)` |
| 接口测试 | `TestClient` + pytest |
| 调试启动 | `uvicorn.run(app, ...)` |

到这里 FastAPI 官方教程的核心就过完了：从第一个接口到依赖注入、安全认证、再到能拆文件上线的项目结构。
