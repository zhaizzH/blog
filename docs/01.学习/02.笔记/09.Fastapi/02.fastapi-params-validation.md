# FastAPI 参数校验与嵌套模型

> 给查询参数、路径参数加长度/范围/正则校验，用 Field 约束模型字段，模型套模型处理复杂 JSON，再收编 Cookie 和 Header——校验体系一次讲完。

## 一、查询参数校验（Query + Annotated）

### 1.1 Annotated + Query 基本用法

上一章的 `q: str | None = None` 只能声明"可选 + 默认值"。现在加约束：`q` 传了就必须不超过 50 个字符：

```python
from typing import Annotated
from fastapi import FastAPI, Query

@app.get("/items/")
async def read_items(q: Annotated[str | None, Query(max_length=50)] = None):
    ...
```

`Annotated` 把类型和元数据绑在一起：`str | None` 是类型，`Query(max_length=50)` 是校验指令，默认值照旧写在 `= None`。超长返回 422，`/docs` 自动显示最大长度。FastAPI 0.95.0 之前只能把 `Query()` 塞进默认值位置（`q: str | None = Query(default=None, max_length=50)`），老代码常见，新代码统一用 `Annotated`：默认值更直观，漏了必填参数编辑器直接报错。

### 1.2 字符串校验全家桶

`min_length`、`max_length`、`pattern`（正则）叠着用，例如 `Query(min_length=3, max_length=50, pattern="^fixedquery$")`：

| 参数 | 作用 | 示例 |
| ---- | ---- | ---- |
| `min_length` | 最短长度 | `min_length=3` |
| `max_length` | 最长长度 | `max_length=50` |
| `pattern` | 正则匹配 | `pattern="^fixedquery$"` |

`^fixedquery$`：`^` 开头、`$` 结尾，中间精确等于 `fixedquery`。正则不会也别慌，抄着用就行。

### 1.3 默认值和必填

| 写法 | 效果 |
| ---- | ---- |
| `= "fixedquery"`（带 `min_length=3`） | 可选，默认 `"fixedquery"` |
| 不写默认值 | 必填 |
| 类型含 `None`，不写默认值 | 必填，但允许传 `None` |

第三种最绕：必须带参数，值可以是 `None`。

### 1.4 一个参数接收多个值

URL 里同一参数出现多次（`?q=foo&q=bar`），声明成 list 全收到：`q: Annotated[list[str] | None, Query()] = None`。list 查询参数必须显式用 `Query()`，否则会被当成请求体；`list[str]` 校验元素类型，光写 `list` 不校验。

### 1.5 元数据：alias / title / description / deprecated

带连字符的名字（如 `item-query`）不能当变量名，用 `alias` 指定。其它常用元数据：

| 参数 | 作用 |
| ---- | ---- |
| `title` | 文档里的标题 |
| `description` | 文档里的说明文字 |
| `deprecated=True` | 文档里标"已弃用"，给老客户端过渡期 |
| `include_in_schema=False` | 从文档和 OpenAPI 里彻底隐藏 |

### 1.6 自定义校验：AfterValidator

内置校验不够用时，用 Pydantic 的 `AfterValidator` 包一个校验函数，在类型校验之后执行，抛 `ValueError` 就拒绝请求：`id: Annotated[str | None, AfterValidator(check_valid_id)] = None`。要查数据库或外部 API 的校验别用这个，那是依赖项的活。

## 二、路径参数校验（Path）

### 2.1 Path 基本用法

`Path()` 和 `Query()` 用法完全一样，只是作用对象换成路径参数，支持 `Query` 的全部参数：`item_id: Annotated[int, Path(title="The ID of the item to get")]`。

路径参数永远必填——它就在路径里，声明默认值、声明 `None` 都不影响，依然是必需的。

### 2.2 参数排序问题（旧写法才有的坑）

不用 `Annotated` 时，`Path()` 占据默认值位置，Python 不允许"有默认值的参数排在无默认值参数前面"（`item_id: int = Path(...), q: str` 直接报错）。用 `Annotated` 就没这问题，参数顺序随便写。

### 2.3 数值校验

| 参数 | 含义 | 示例 |
| ---- | ---- | ---- |
| `gt` | 大于（greater than） | `gt=0` |
| `ge` | 大于等于（greater or equal） | `ge=1` |
| `lt` | 小于（less than） | `lt=10.5` |
| `le` | 小于等于（less than or equal） | `le=1000` |

`item_id: Annotated[int, Path(title=..., ge=1)]` 要求 `item_id` 是大于等于 1 的整数，`0` 和负数直接 422。数值校验对 `float` 同样有效：`ge=0` 会放行 `0.0`，`gt=0` 才能拦下它。`Query`、`Path` 都是同一个 `Param` 类的子类，共享全部参数。

## 三、请求体字段（Field）

### 3.1 从 pydantic 导入 Field

`Query`、`Path`、`Body` 都从 `fastapi` 导入，`Field` 不一样——它是 Pydantic 的东西，`fastapi` 里没有它，弄混了直接 ImportError。

### 3.2 用 Field 声明模型属性

```python
from pydantic import BaseModel, Field

class Item(BaseModel):
    name: str
    description: str | None = Field(default=None, title="The description of the item", max_length=300)
    price: float = Field(gt=0, description="The price must be greater than zero")
```

写法同函数参数，只是把 `Query`/`Path` 换成 `Field`。对照：

| 写法 | 位置 | 作用 |
| ---- | ---- | ---- |
| `Query(gt=0)` | 函数参数 | 校验查询参数 |
| `Path(gt=0)` | 函数参数 | 校验路径参数 |
| `Body(embed=True)` | 函数参数 | 声明请求体参数 |
| `Field(gt=0)` | 模型属性 | 校验模型字段 |

`Field` 和 `Query`、`Path` 共用同一套校验参数（`default`、`gt`/`ge`、`lt`/`le`、`max_length`/`min_length`、`title`、`description`）。`price: float = Field(gt=0)`：传 `-1` 直接 422。

### 3.3 小心：额外键会进 OpenAPI

传给 `Field` 的额外关键字参数会原样进 OpenAPI schema：标准元数据能被 Swagger UI 展示，但自己发明的键规范里没有，严格校验工具可能报错。自定义元数据想清楚再加。

## 四、多参数与嵌套模型

### 4.1 请求体里拆多个参数

一个请求体里能拆出多个 Pydantic 模型参数，FastAPI 用参数名当请求体的键。再声明 `User` 模型，函数参数写 `item: Item, user: User`，请求体变成两层 `{"item": {...}, "user": {...}}`——同一个 `item` 现在必须嵌在 `item` 键里。`item: Item | None = None` 还能让请求体整体可选。

想在请求体里加裸值（如 `importance: 5`）？单一类型默认被当成查询参数，必须用 `Body()` 标记，还能加校验：`Annotated[int, Body(gt=0)]`。

只有一个 `item: Item` 时，默认期望的请求体是拍平的模型字段；想包层 `item` 键，用 `Body(embed=True)`——请求体从 `{"name": ...}` 变成 `{"item": {...}}`。

### 4.2 嵌套模型

模型里套模型、套列表、套字典，JSON 结构多复杂都行——Pydantic 负责校验、转换、生成文档，全自动：

```python
from pydantic import BaseModel, HttpUrl

class Image(BaseModel):
    url: HttpUrl
    name: str

class Item(BaseModel):
    name: str
    description: str | None = None
    price: float
    tags: set[str] = set()              # set 自动去重
    image: Image | None = None          # 嵌套模型
    images: list[Image] | None = None   # 模型列表
```

- `tags: set[str]`：`["rock", "rock", "metal"]` 进去，`{"rock", "metal"}` 出来，自动去重，文档标 `uniqueItems: true`。`list[str]` 校验元素类型，光写 `list` 不校验
- `image: Image | None`：嵌套对象，内层字段被逐层校验，自动补全、转换、文档照常生效
- `images: list[Image]`：数组每个元素单独校验，缺 `url` 照样 422；`url: HttpUrl` 是 Pydantic 的 URL 类型，`"not-a-url"` 直接 422

嵌套没有深度限制，三层、四层随便套。请求体最外层就是数组时，函数参数直接写 `images: list[Image]`。键名未知时声明 `dict`：`weights: dict[int, float]`——JSON 只允许字符串键，Pydantic 自动转换。

## 五、Cookie 与 Header 参数

### 5.1 Cookie：必须用 Cookie() 声明

登录状态、埋点 ID 这些存在浏览器里的数据，用 `Cookie()` 声明就能在接口里读到——写法跟 `Query`、`Path` 一模一样：`ads_id: Annotated[str | None, Cookie()] = None`。

cookie 参数可必填、可选、带默认值、加校验：`Annotated[str, Cookie()]` 必填；`Cookie(default="abc")` 带默认值；`Cookie(max_length=50)` 超长 422。**必须用 `Cookie()` 标注**，不写会被当成查询参数处理。cookie 由浏览器幕后管理，JavaScript 拿不到也发不出去，Swagger UI 里填了值也不会真发送，想真测用 curl 带 `-H "Cookie: ads_id=123"`。

::: warning 警告
别在 cookie 里存敏感信息（token、密码等）——cookie 随每个请求自动发送，适合存埋点标识。
:::

### 5.2 Header：下划线自动转连字符

`Header()` 结构跟 `Query` 一样，不标会被当查询参数：`user_agent: Annotated[str | None, Header()] = None`。HTTP 头惯例用连字符（`User-Agent`、`X-Token`），但 `user-agent` 不是合法变量名，`Header` 默认把下划线转成连字符：

| 函数参数 | 实际读取的请求头 |
| ---- | ---- |
| `user_agent` | `User-Agent` |
| `x_token` | `X-Token` |

确有下划线请求头时，设 `convert_underscores=False`，但要慎用——不少代理和服务器根本不支持带下划线的请求头。同一个请求头发多次时，声明成 `list[str]` 全收。

### 5.3 Cookie/Header 参数模型

接口要收三四个 cookie/header，与其在函数签名里堆一串参数，不如建一个 Pydantic 模型一次性声明（0.115.0+），比如 `Cookies` 模型（`session_id: str` 必填，其余可选），函数参数写 `cookies: Annotated[Cookies, Cookie()]`。

参数类型标注成模型，外面再包一层 `Cookie()`（或 `Header()`），告诉 FastAPI「数据从 cookie/header 里取」。FastAPI 按字段名逐个取值，转换、校验、缺必填就 422，全是 Pydantic 的活。模型可在多个接口复用，加字段改一处全生效；header 模型同样适用下划线转连字符（`save_data` ↔ `save-data`）。

想收紧白名单，模型加一行 `model_config = {"extra": "forbid"}`，多传没声明的直接 422，`loc` 标得明明白白（`["cookie", "santa_tracker"]`）。单个参数、模型、白名单三种玩法，对应 `x: Annotated[str, Cookie()]`、`Annotated[Cookies, Cookie()]`、`extra: forbid`；header 保留下划线用 `Header(convert_underscores=False)`，慎用。

## 六、示例数据与额外类型（压缩节）

### 6.1 查询参数模型

一坨相关的查询参数（分页、排序、筛选）也能收进一个 Pydantic 模型（0.115.0+），一处声明、处处复用。函数参数声明成 `Annotated[FilterParams, Query()]`，FastAPI 从查询字符串里提取每个字段，`/docs` 里分开展示：

```python
class FilterParams(BaseModel):
    limit: int = Field(100, gt=0, le=100)
    offset: int = Field(0, ge=0)
    order_by: Literal["created_at", "updated_at"] = "created_at"
    tags: list[str] = []
```

`Field(...)` 与 `Query(...)` 一一对应，同样可 `extra: forbid` 禁止多余参数。参数多且相关时用模型，一两个别过度设计。

### 6.2 请求示例数据

给接口声明示例数据，Swagger UI 直接展示、一键填充，四种声明方式：

| 场景 | 用哪个 |
| ---- | ---- |
| 模型全局一个示例 | `model_config` 里的 `json_schema_extra` |
| 单个字段示例 | `Field(examples=[...])` |
| 请求体一个示例 | `Body(examples=[...])` |
| 文档里切换多个示例 | `Body(openapi_examples={...})` |

`openapi_examples` 的外层 dict 键是示例名，值里有 `summary`、`description`、`value`，文档 UI 里出现下拉框切换。只需要一个示例就用 `examples`，要切换多个就上 `openapi_examples`。

### 6.3 额外数据类型

除了 `int`、`str`、`float`、`bool`，这些类型也能直接标注，FastAPI 负责和 JSON 互转，函数里拿到的是真正的 Python 对象：

| 类型 | 请求/响应中的样子 | 说明 |
| ---- | ---- | ---- |
| `UUID` | 字符串 | 通用唯一标识符，常当 ID 用 |
| `datetime` | ISO 8601 字符串 | 日期 + 时间 |
| `date` / `time` | `2008-09-15` / `14:23:55` | 日期 / 时间 |
| `timedelta` | 浮点数（总秒数） | 时间差 |
| `bytes` | 字符串 | schema 标 `binary` |
| `Decimal` | 按 `float` 处理 | 高精度十进制 |

`datetime` 参数可以直接加 `timedelta` 做运算，响应里自动转回 ISO 8601 字符串、`timedelta` 输出成秒数。日期格式写错（如 `2008/09/15`）直接 422。
