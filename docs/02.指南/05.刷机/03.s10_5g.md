# 三星 S10 5G 韩版刷入官方固件并获取 Root

## 前言

给 **三星 Galaxy S10 5G (SM-G977N / beyondx)**，覆盖刷入官方 4.0 底包 → 刷入 TWRP → 刷入KernelSU-Next → 安装 KernelSU-Next 管理 root

刷机模式打开方式,首先连接数据线，重启/关机

**卡刷**:音量加+Bixby 键+关机键

**线刷**:音量减+Bixby 键

**重启**:音量减+关机键

::: warning 警告
刷机有风险，操作前请备份重要数据，确保手机已完成 Bootloader 解锁且电量充足
:::

### 固件

### 工具与驱动

### 安装驱动

运行 **三星驱动** 安装包，全程点击下一步完成安装

## 刷入底包

1. 手机必须连接电脑再按 `音量减+Bixby 键` 进入 **挖煤模式 (Download)** 并打开 **Odin3**
2. 解压下载好的 **固件包**，在 Odin3 中对应槽位（`BL` / `AP` / `CP` / `CSC`）选入文件并开始刷入

## 刷入 TWRP 与第三方 ROM

### 刷入并进入 TWRP

1. 挖煤模式下打开 **Odin3**，选择 `AP` 槽位导入 **TWRP** 镜像并刷入
2. 刷入完成瞬间立即同时按住 **音量上 + Bixby 键 + 电源键** 不松手，直至进入 TWRP 界面
3. 点击 **安装** 查看目录是否乱码；若有乱码，进入 **清除** 执行恢复出厂设置和格式化 Data (输入 yes 界面)
4. 清除完成后务必点击 **重启 → 恢复模式 (Recovery)** 重新进入 TWRP


### 推送并刷入内核

1. 手机保持 TWRP 模式连接电脑，将下载好的 [GoRhanHee_Kernel_for_beyondxks_ksun.zip](https://github.com/GoRhanHee/android_kernel_samsung_exynos9820) 复制到手机
2. 在 TWRP 中点击 **安装**，选择推送好的内核刷入，完成后执行一次双清再重启
3. 开机后安装 [KernelSU-Next v3.2.0 apk](https://github.com/KernelSU-Next/KernelSU-Next/releases/download/v3.2.0/KernelSU_Next_v3.2.0_33129-release.apk) 即可管理 root
