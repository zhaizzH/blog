# 三星 S10 5G 刷机与获取 Root

## 前言

本文适用于 **三星 Galaxy S10 5G (SM-G977N / beyondx)**，全程使用图形化工具（免 ADB 命令行），覆盖刷入官方 4.0 底包 → 刷入 TWRP 与类原生系统 → 刷入 Lineage Recovery → 修补 Boot 获取 Magisk Root

::: warning 警告
刷机有风险，操作前请备份重要数据，确保手机已完成 Bootloader 解锁且电量充足（建议 60% 以上）
:::

## 准备工作

### 固件与 ROM 清单

- **官方 4.0 固件**：[SamFw (SM-G977N)](https://samfw.com/firmware/SM-G977N)
- **第三方类原生 ROM**：[PixelExtended_beyondx-12.0-20220207-0222-UNOFFICIAL](https://www.yhcres.top/02-%E6%89%8B%E6%9C%BA%E5%B9%B3%E6%9D%BF/%E4%B8%89%E6%98%9FSamsung%20Galaxy/Galaxy%20S10%205G%EF%BC%88beyondx%EF%BC%89/%E7%B1%BB%E5%8E%9F%E7%94%9F/PixelExtended_beyondx-12.0-20220207-0222-UNOFFICIAL)

### 工具与驱动清单

- 三星官方驱动 & 安卓驱动
- Odin3 刷机工具 & 搞机助手
- TWRP Recovery & Lineage Recovery (`193.tar`)
- Magisk 24.1

::: info 提示
以上资源均来自于互联网，已有对应驱动和工具的可跳过下载
:::

### 安装驱动

1. 运行 **三星驱动** 安装包，全程点击下一步完成安装
2. 解压并打开 **安卓驱动** 文件夹，安装列表中的第一个驱动

## 刷入官方 4.0 底包

1. 手机关机进入 **挖煤模式 (Download)** 并连接电脑，打开 **Odin3**
2. 解压下载好的 **SM-G977N 官方 4.0 固件**，在 Odin3 中对应槽位（`BL` / `AP` / `CP` / `CSC`）选入文件并开始刷入
3. 刷完后手机自动重启至官方 Recovery，执行 **双清**（Wipe data/factory reset 与 Wipe cache partition）后进入系统
4. 开机前先拔卡、断网跳过 Google 引导，进入系统后连接 WiFi 检查系统是否为最新版本（非最新则先更新，已是最新则重启重新进入挖煤模式）

## 刷入 TWRP 与第三方 ROM

### 1. 刷入并进入 TWRP

1. 挖煤模式下打开 **Odin3**，选择 `AP` 槽位导入 **TWRP** 镜像并刷入
2. 刷入完成瞬间立即同时按住 **音量上 + Bixby 键 + 电源键** 不松手，直至进入 TWRP 界面
3. 点击 **安装** 查看目录是否乱码；若有乱码，进入 **清除** 执行恢复出厂设置和格式化 Data
4. 清除完成后务必点击 **重启 → 恢复模式 (Recovery)** 重新进入 TWRP

::: warning 警告
格式化 Data 后必须立即重启回 Recovery，否则后续分区挂载异常会导致刷机失败
:::

### 2. 推送并刷入 ROM

1. 手机保持 TWRP 模式连接电脑，打开 **搞机助手** → 选择 **恢复模式** → 点击 **推送文件**，将 `PixelExtended` 刷机包推送至手机
2. 在 TWRP 中点击 **安装**，选择推送好的刷机包刷入，完成后执行一次双清

## 刷入 Lineage Recovery

1. 打开 **搞机助手**，控制手机重启进入 **挖煤模式**
2. 打开 **Odin3**，选择 `AP` 槽位刷入 **Lineage Recovery (`193.tar`)**
3. 刷完立即按住 **音量上 + Bixby 键 + 电源键** 不松手进入 Lineage Recovery，执行双清后选择重启进入系统

## 获取 Magisk Root

1. 手机连接电脑，在电脑端解压 `PixelExtended` 刷机包，提取出 `boot.img` 文件并传至手机
2. 手机安装并打开 **Magisk 24.1** → 点击 **安装** → **选择并修补一个文件**，选中刚刚传入的 `boot.img`
3. 修补完成后，在手机 `Download` 目录下找到生成的修补镜像文件，复制到电脑桌面
4. 打开 **搞机助手** 将手机重启至 **恢复模式 (Recovery)**，在手机 Recovery 界面开启 Fastboot 模式
5. 搞机助手识别到 Fastboot 连接后，切换至 **引导模式**，刷入桌面上修补好的 `boot` 镜像，刷完重启系统即可
