

# MIX2S 刷机

# 准备工作

## 刷机包选择 
[类原生](https://h5.cloud.189.cn/share.html#/t/mE7VBnJZVJNb)或者国内定制 ROM

## Recovery 选择 
[橙狐](https://orangefox.download/device/5e59825977c93477b29eae0e),根据不同安卓版本选择对应的 Recovery 刷入。

## 刷入 ROM
类原生 ROM 一般使用 `adb sideload ROM包路径` 刷入，国内定制 ROM 作者会有相应的刷机教程。

## Googplay 服务
[BITGAPPS](https://bitgapps.io/),选择 Core 版本，安卓版本选择对应的版本，下载后通过 Recovery 安装或者使用 ROOT 管理器安装。

## 刷入 Windows

进入 `Mindows` [官网](https://mindows.cn/index.html)，下载 [脚本版 V8](https://syxz.lanzoub.com/b01f6c1bc) （密码：ghnk）

下载 [Windows 镜像](https://1779130.share.123pan.cn/123pan/8eP9-5YvGA.html)

进入工具箱后先选择机型，再导入 Recovery，最后选择一键安装 Windows

- Windows 切换安卓，[Mindows 一键切换](https://1779130.share.123pan.cn/123pan/8eP9-n2TGA)

- 安卓切换 Windows，[Mindows 助手](https://1779130.share.123pan.cn/123pan/8eP9-KDTGA)

### Apatch 使用 System 分区

1. 打开目录 /data/adb/modules 创建 `.rw` 文件夹
2. 打开 `.rw` 目录，创建 `system` 文件夹
3. 打开 `system` 目录，创建 `upperdir` 与 `workdir` 两个文件夹。创建完毕 重启手机。

或者使用命令创建
```bash
mkdir -p /data/adb/modules/.rw/system/{upperdir,workdir}
```
