# 小米 MIX 2S 刷机

## 前言

小米 MIX 2S 作为一款经典机型，刷机资源丰富，支持类原生 ROM、国内定制 ROM 甚至 Windows 系统。本文汇总刷机全流程，涵盖解锁 Bootloader → 刷入 Recovery → 刷入 ROM → 安装 Google Play 服务 → 可选刷入 Windows → ROOT 等步骤。

::: warning 警告
刷机有风险，操作前请备份重要数据，确保电量充足（建议 60% 以上）
:::

## 准备工作

### 刷机包选择

- **类原生 ROM**：[Mi-Mix2s-ROMs](https://h5.cloud.189.cn/share.html#/t/mE7VBnJZVJNb) — 收录多种类原生系统，体验接近 AOSP
- **国内定制 ROM**：根据个人需求选择，一般在酷安搜索上车（如 Flyme、MIUI 等）

### Recovery 选择

[橙狐 Recovery (OrangeFox)](https://orangefox.download/device/5e59825977c93477b29eae0e)，根据不同安卓版本选择对应的 Recovery 刷入

- 进入官网后选择对应 MIX 2S 的 Recovery 包
- 注意区分 Android 版本（如 Android 12/13/14），确保 Recovery 与 ROM 版本匹配

### 解锁 Bootloader

1. 前往 [小米官方解锁平台](https://www.miui.com/unlock/) 申请解锁资格
2. 下载小米解锁工具并登录小米账号
3. 手机进入 Fastboot 模式（关机后同时按住 **音量下 + 电源键**）
4. 连接电脑，运行解锁工具按提示操作

::: info 提示
新绑定的小米账号通常需要等待 7 天才能解锁，请提前准备
:::

### 驱动安装

确保电脑已安装以下驱动：

- **ADB / Fastboot 驱动**：可通过 [Universal ADB Drivers](https://adbdriver.com/) 或安装 [Android Studio Platform Tools](https://developer.android.com/studio/releases/platform-tools)
- **9008 深度刷机驱动**（刷 Windows 系统时需要）

## 刷入 Recovery

### 方法一：Fastboot 刷入（推荐）

```bash
fastboot flash recovery 你的recovery文件名.img
fastboot reboot recovery
```

### 方法二：使用一键刷入工具

部分开发者提供了一键刷入脚本，按照工具提示操作即可

## 刷入 ROM

### 类原生 ROM

类原生 ROM 一般使用 `adb sideload` 方式刷入：

```bash
adb sideload ROM包路径.zip
```

操作步骤：

1. 将手机重启至 Recovery 模式
2. 选择 **高级** → **ADB Sideload** 或直接选择 **应用 ADB Sideload**
3. 在电脑端执行上述命令
4. 等待进度条完成，重启手机

### 国内定制 ROM

国内定制 ROM 作者通常会有相应的刷机教程及专属工具，请按照对应教程操作。一般为 Recovery 双清后直接安装 ROM 包，或通过专属 PC 工具刷入。

## Google Play 服务（可选）

若使用类原生 ROM 通常不自带 Google 服务，可刷入 [BitGapps](https://bitgapps.io/)：

- 选择 **Core 版本**，体积小巧，包含基础 Google Play 服务
- 下载与 ROM 安卓版本对应的包

::: info 提示
下载后通过 Recovery 安装，或者使用 ROOT 管理器安装

建议在刷入 ROM 后 **第一时间** 安装 Google Play 服务，避免后续出现兼容性问题
:::

## 刷入 Windows 系统（可选）

MIX 2S 支持刷入 Windows 11 ARM 系统，实现双系统运行。

### 1. 下载工具

- **Mindows 脚本工具**：[脚本版 V8](https://syxz.lanzoub.com/b01f6c1bc)（密码：ghnk）
- **Windows 镜像**：[123 云盘下载](https://1779130.share.123pan.cn/123pan/8eP9-5YvGA.html)
- 更多资源见 [Mindows 官网](https://mindows.cn/index.html)

### 2. 安装 Windows

进入工具箱后按以下步骤操作：

1. 选择对应机型（MIX 2S）
2. 导入 Recovery
3. 选择一键安装 Windows，等待完成

### 3. 系统切换

安装 Windows 后，工具箱目录下会生成对应的 `UEFI.img` 文件用于切换系统：

- **Windows → 安卓**：[Mindows 一键切换](https://1779130.share.123pan.cn/123pan/8eP9-n2TGA) — 需要对应 ROM 的 `boot.img` 文件
- **安卓 → Windows**：[Mindows 助手](https://1779130.share.123pan.cn/123pan/8eP9-KDTGA) — 需要 `UEFI.img` 文件

## ROOT

### ROOT 管理器

- **[Magisk](https://github.com/topjohnwu/Magisk)** — 最主流的 ROOT 方案，模块生态丰富
- **[APatch](https://github.com/bmax121/APatch)** — 支持内核级 ROOT
- **[KernelSU](https://github.com/tiann/KernelSU)** — 内核级 ROOT 方案

### 模块

- [LSPosed](https://github.com/re-zero001/LSPosed-Irena/releases/tag/2.0.0) — Xposed 框架，支持模块化功能增强
- [ZygiskNext](https://github.com/Dr-TSNG/ZygiskNext/releases/tag/v1.3.4) — Zygisk 注入框架
- [一加桌面](https://www.lanzoux.com/iuWpEkl3paj)（限安卓 10 和 11）
- [GMS-DOZE](https://github.com/gloeyisk/universal-gms-doze/releases/tag/1.9.2) — 使 Google Play 服务进入 DOZE 省电模式
- [FckVIP](https://github.com/bug-bit/fckvip/releases/tag/v6.0.2-ref.r508.287fcee) — 解锁部分软件会员与拓展功能增强

### APatch 使用 System 分区

#### 方法一：手动创建

1. 打开目录 `/data/adb/modules`，创建 `.rw` 文件夹
2. 进入 `.rw` 目录，创建 `system` 文件夹
3. 进入 `system` 目录，创建 `upperdir` 与 `workdir` 两个文件夹
4. 创建完毕后重启手机

#### 方法二：命令创建

```bash
mkdir -p /data/adb/modules/.rw/system/{upperdir,workdir}
```

## 注意事项

✅ 刷机前备份所有重要数据（联系人、照片、应用数据等）

✅ 确保电脑已安装 ADB/Fastboot 驱动，避免连接异常

✅ 下载 ROM 后校验文件完整性，避免刷入损坏的包

✅ 刷机完成后建议先进入 Recovery 双清（Factory Reset）再重启

⚠️ 不同 ROM 对应不同安卓版本，Recovery 和 GApps 需版本匹配

⚠️ 刷入 Windows 系统会占用存储空间，建议保留至少 64GB 可用空间

⚠️ 若刷机失败无法开机，进入 Recovery 重新刷入或使用小米助手线刷回官方系统
