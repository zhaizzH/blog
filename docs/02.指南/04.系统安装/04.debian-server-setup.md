# Debian 本地服务器开荒

> 从零到一搭建一台 Debian 本地服务器：先做基础环境优化，再铺全套运行环境（React + Python + Java），最后 Nginx 统一托管上线。

## 一、开荒总览

### 1.1 硬件环境

| 项目 | 说明 |
| ---- | ---- |
| 系统 | Debian 13 (Trixie)，带 KDE Plasma |
| 内存 | 4GB |
| 屏幕 | 2160x1440 |

### 1.2 目标架构

| 层 | 技术 | 端口 | 说明 |
| ---- | ---- | ---- | ---- |
| 前端 | React | - | 打包静态文件，Nginx 直接托管，无后台进程 |
| 后端 | Java SpringBoot | 8080 | 打包 Jar，Systemd 守护运行 |
| 后端 | Python FastAPI/Flask | 8090 | uvicorn/gunicorn，Systemd 守护运行 |
| 网关 | Nginx | 80 | 统一反向代理，所有接口对外出口 |
| 配套 | Redis / MariaDB | - | 按需启用 |

### 1.3 开荒路线

1. **系统初始化**：更新系统、装通用依赖
2. **终端体验**：TTY 字体放大，高分屏不再看瞎眼
3. **内存策略**：纯终端模式挂机，4GB 内存余量最大化
4. **运行环境**：JDK21、Python、Node 22
5. **网关服务**：Nginx + Redis + MariaDB
6. **项目部署**：Java / Python / React 三套 Systemd 规范
7. **一键校验**：全环境验证

## 二、系统初始化

```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git vim unzip net-tools build-essential
```

## 三、TTY 界面字体放大

纯 TTY 黑底控制台（`Ctrl+Alt+F1~F6`）**不支持 `Ctrl++` / `Ctrl+-` 缩放**，只能替换字体文件改大小。

### 3.1 安装大号字体库

```bash
sudo apt install -y fonts-terminus console-setup console-setup-linux
```

### 3.2 配置 console-setup

```bash
sudo dpkg-reconfigure console-setup
```

按顺序选择：

1. **编码**：`UTF-8`
2. **字符集**：`Guess optimal character set`
3. **字体**：`Terminus`
4. **字号**（高分屏最大）：`16x32`

或手动写入固定配置 `/etc/default/console-setup`：

```bash
sudo tee /etc/default/console-setup <<'EOF'
ACTIVE_CONSOLES="/dev/tty[1-6]"
CHARMAP="UTF-8"
CODESET="guess"
FONTFACE="Terminus"
FONTSIZE="16x32"
EOF
sudo setupcon    # 生效，切换 TTY Ctrl+Alt+F1~F6 立即应用，重启不还原
```

### 3.3 GRUB 开机界面同步放大

```bash
sudo nano /etc/default/grub
```

```
GRUB_GFXMODE=2160x1440      # 按屏幕原生分辨率填写
GRUB_GFXPAYLOAD_LINUX=keep
GRUB_CMDLINE_LINUX_DEFAULT="quiet"
```

```bash
# 用 32 号字重生成 GRUB 大字字体
sudo grub-mkfont -s 32 -o /boot/grub/fonts/unicode.pf2 /usr/share/fonts/truetype/dejavu/DejaVuSansMono.ttf
sudo update-grub
```

### 3.4 字号推荐 & 临时切换

| 屏幕类型 | 推荐字号 |
| -------- | -------- |
| 2160x1440 | `16x32` |
| 1920x1080 | `14x28` |
| 1280x720  | `12x24` |

```bash
# 临时切换字体（重启还原）
sudo setfont /usr/share/consolefonts/Uni3-Terminus16x32.psf.gz

# 恢复默认（字体选 VGA，字号默认）
sudo dpkg-reconfigure console-setup
```

## 四、内存策略：图形 / 纯终端模式

### 4.1 永久切换开机模式

```bash
# 默认【纯终端开机】
sudo systemctl set-default multi-user.target

# 默认【图形桌面开机】
sudo systemctl set-default graphical.target
```

### 4.2 关闭后台偷跑服务

```bash
sudo systemctl disable --now bluetooth  # 蓝牙
sudo systemctl disable --now cups      # 打印机
sudo systemctl disable --now avahi-daemon # mDNS / Zeroconf
balooctl disable    # KDE 文件索引
```

### 4.3 临时切换（无需重启）

```bash
# 终端 → 临时开启桌面
sudo systemctl start sddm          # 切桌面快捷键 Ctrl+Alt+F7

# 桌面 → 立刻关闭释放内存
sudo systemctl stop sddm           # 切纯终端快捷键 Ctrl+Alt+F3~F6
```

临时切换不改变开机默认模式，关掉桌面后内存立即回落。

### 4.4 内存查看命令

```bash
free -h                           # 整体内存
htop                              # 进程可视化监控
ps aux --sort=-%mem | head -6     # 最吃内存的进程
```

## 五、关闭屏幕显示

> 四种场景：纯文字控制台(tty)、Xorg 桌面、Wayland 桌面、开机永久黑屏。

### 5.1 临时一键关闭屏幕

**Xorg 桌面（X11，GNOME/XFCE/MATE/Cinnamon）**

```bash
xset dpms force off   # 显示器断电休眠，任意键鼠唤醒
xset dpms force on    # 恢复屏幕
```

单显示器彻底关闭输出：

```bash
xrandr                          # 先查屏幕名称（HDMI-1/VGA-1）
xrandr --output HDMI-1 --off
xrandr --output HDMI-1 --auto
```

**Wayland 桌面（Debian12 GNOME 默认、Sway）**

```bash
# GNOME Wayland 息屏断电
gdbus call --session --dest org.gnome.Mutter.DisplayConfig --object-path /org/gnome/Mutter/DisplayConfig --method org.gnome.Mutter.DisplayConfig.PowerSaveMode 1
# 恢复
gdbus call --session --dest org.gnome.Mutter.DisplayConfig --object-path /org/gnome/Mutter/DisplayConfig --method org.gnome.Mutter.DisplayConfig.PowerSaveMode 0

# Sway / WLroots
wlr-randr --output HDMI-A-1 --off
```

**TTY 纯字符控制台**

方式1：内核帧缓冲（ssh 也能执行）

```bash
echo 1 | sudo tee /sys/class/graphics/fb0/blank   # 1=黑屏，0=点亮
echo 0 | sudo tee /sys/class/graphics/fb0/blank
```

方式2：本地终端 setterm（仅当前 tty）

```bash
setterm -blank 1 -powersave powerdown   # 黑屏
setterm -blank 0 -powersave off         # 恢复
```

### 5.2 永久开机自动关闭屏幕

**方案A：内核参数（全局所有控制台）**

```bash
sudo nano /etc/default/grub
```

```ini
GRUB_CMDLINE_LINUX_DEFAULT="quiet splash consoleblank=1"
```

```bash
sudo update-grub
sudo reboot
```

`consoleblank=0` 永不黑屏，`consoleblank=600` 10 分钟自动黑屏。

**方案B：systemd 服务开机自动黑屏（Debian 11/12）**

```bash
sudo nano /etc/systemd/system/blank-screen.service
```

```ini
[Unit]
Description=Turn off screen after boot
After=multi-user.target
Type=idle

[Service]
ExecStart=/bin/sh -c "sleep 2; echo 1 > /sys/class/graphics/fb0/blank"

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now blank-screen.service
```

**方案C：Xorg 桌面永久关闭自动息屏**

```bash
xset s off -dpms s noblank
```

写入开机自启脚本即永久生效。

### 5.3 桌面图形界面设置（可视化自动息屏）

1. **GNOME**：设置 → 电源 → 显示器，设置闲置几分钟关闭屏幕
2. **XFCE**：设置 → 电源管理器 → 显示，调整关闭显示器时间
3. **KDE Plasma**：系统设置 → 电源管理 → 屏幕节能

### 5.4 笔记本合盖只关屏、不关机/休眠

```bash
sudo nano /etc/systemd/logind.conf
```

```ini
HandleLidSwitch=ignore
HandleLidSwitchExternalPower=ignore
```

```bash
sudo systemctl restart systemd-logind
```

## 六、Java 运行环境

### 6.1 安装 JDK21

```bash
sudo apt install -y openjdk-21-jdk
```

### 6.2 多版本切换 & 环境变量

```bash
sudo update-alternatives --config java
sudo update-alternatives --config javac

# 自动配置环境变量（登录自动加载）
sudo tee /etc/profile.d/java.sh <<'EOF'
export JAVA_HOME=$(dirname $(dirname $(readlink -f $(which java))))
export PATH=$JAVA_HOME/bin:$PATH
EOF
source /etc/profile.d/java.sh
```

### 6.3 校验

```bash
java -version && javac -version && echo $JAVA_HOME
```

## 七、Python 运行环境

两套方案二选一。

### 方案1：系统原生 Python（简单、自用/小型项目）

```bash
sudo apt install -y python3 python3-pip python3-venv
```

### 方案2：pyenv 多版本隔离（多项目共存）

```bash
sudo apt install -y git curl build-essential libssl-dev zlib1g-dev \
  libbz2-dev libreadline-dev libsqlite3-dev libffi-dev liblzma-dev
curl https://pyenv.run | bash
echo 'export PATH="$HOME/.pyenv/bin:$PATH"' >> ~/.bashrc
echo 'eval "$(pyenv init -)"' >> ~/.bashrc
exec $SHELL
pyenv install 3.12
pyenv global 3.12
```

校验：`python3 --version`、`pip3 --version`

## 八、Node.js 前端环境（React 打包用）

```bash
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
node -v && npm -v
```

::: tip 前端部署核心逻辑
1. 服务器执行 `npm run build` 生成静态资源
2. **无需常驻 Node 进程**，由 Nginx 直接托管静态文件
:::

## 九、Nginx 统一网关

### 9.1 安装启动

```bash
sudo apt install -y nginx
sudo systemctl enable --now nginx
```

### 9.2 通用全站配置

路径：`/etc/nginx/sites-available/web`

```nginx
server {
    listen 80;
    server_name _;

    # 前端静态资源
    root /var/www/web/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }

    # Java 后端 (SpringBoot :8080)
    location /api/java/ {
        proxy_pass http://127.0.0.1:8080/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # Python 后端 (FastAPI/Flask :8000)
    location /api/python/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

### 9.3 启用配置 & 生效

```bash
sudo ln -s /etc/nginx/sites-available/web /etc/nginx/sites-enabled/web
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t && sudo systemctl reload nginx
```

## 十、项目最终部署规范

| 项目 | 技术 | 运行方式 | 端口 | 对外暴露 |
| ---- | ---- | -------- | ---- | -------- |
| Java | SpringBoot | 打包 Jar，Systemd 守护 | 8080 | Nginx 反向代理 |
| Python | FastAPI/Flask | uvicorn/gunicorn，Systemd 守护 | 8090 | Nginx 反向代理 |
| React | 前端静态 | 打包静态文件，Nginx 托管 | - | Nginx 直接托管 |

### 10.1 SpringBoot（端口 8080）

```bash
mvn clean package
sudo cp target/app.jar /opt/app/app.jar
```

`/etc/systemd/system/springboot.service`：

```ini
[Unit]
Description=SpringBoot Application
After=network.target mariadb.service

[Service]
User=www-data
WorkingDirectory=/opt/app
ExecStart=/usr/bin/java -jar /opt/app/app.jar --server.port=8080
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now springboot
```

### 10.2 Python FastAPI（端口 8090）

```bash
python3 -m venv /opt/python/venv
/opt/python/venv/bin/pip install fastapi uvicorn
```

`/etc/systemd/system/fastapi.service`：

```ini
[Unit]
Description=FastAPI Application
After=network.target

[Service]
User=www-data
WorkingDirectory=/opt/python/app
ExecStart=/opt/python/venv/bin/uvicorn main:app --host 0.0.0.0 --port 8000
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now fastapi
```

### 10.3 React 前端

```bash
npm install
npm run build                    # 生成 dist/ 静态资源
sudo cp -r dist/* /var/www/web/dist/
```

### 10.4 访问入口

- `http://服务器IP/` → React 前端
- `http://服务器IP/api/java/` → Java SpringBoot 后端
- `http://服务器IP/api/python/` → Python FastAPI/Flask 后端
