# Debian 安装 Intel 核显驱动

> 在 Debian 13 (Trixie) 上安装 Intel 核显的计算与媒体驱动，启用 OpenCL、Level Zero、VA-API 硬解硬编与 oneVPL 媒体处理能力，适用于 Jellyfin / FFmpeg 转码、推理框架等 GPU 场景。

## 一、环境说明

| 项目 | 说明 |
| ---- | ---- |
| 系统 | Debian 13 (Trixie) amd64 |
| 核显 | Intel Iris Xe Graphics（Alder Lake-P） |
| 目标 | OpenCL / Level Zero / VA-API / oneVPL 媒体驱动 |

::: warning 跨发行版源提示
Intel 官方 GPU 仓库目前提供的是 Ubuntu Noble（24.04）软件源。Debian 13 可以使用其中的相关组件，但属于跨发行版使用软件源，建议确认依赖关系可控后再用于生产环境。
:::

## 二、添加 Intel GPU 软件源

导入仓库 GPG key：

```bash
wget -qO - https://repositories.intel.com/gpu/intel-graphics.key | sudo gpg --dearmor --output /usr/share/keyrings/intel-graphics.gpg
```

添加软件源：

```bash
echo "deb [arch=amd64,i386 signed-by=/usr/share/keyrings/intel-graphics.gpg] https://repositories.intel.com/gpu/ubuntu noble client" | sudo tee /etc/apt/sources.list.d/intel-gpu-noble.list
```

更新软件包索引：

```bash
sudo apt update
```

## 三、安装驱动组件

一键安装 OpenCL、Level Zero、VA-API、Intel Media Driver、oneVPL 及常用检测工具：

```bash
sudo apt install -y libze-intel-gpu1 libze1 intel-metrics-discovery intel-opencl-icd intel-gsc \
  intel-media-va-driver-non-free libmfx-gen1 libvpl2 libvpl-tools libva-glx2 va-driver-all \
  vainfo clinfo
```

各包作用：

| 包名 | 说明 |
| ---- | ---- |
| `intel-opencl-icd` | Intel OpenCL 运行时 |
| `libze1` | Level Zero loader |
| `libze-intel-gpu1` | Intel Level Zero GPU runtime |
| `intel-metrics-discovery` | Intel GPU 性能指标组件 |
| `intel-gsc` | Intel Graphics Security Controller 组件 |
| `intel-media-va-driver-non-free` | Intel VA-API Media Driver |
| `libmfx-gen1` | Intel Media SDK / oneVPL 相关运行库 |
| `libvpl2` / `libvpl-tools` | oneVPL 运行库与工具 |
| `libva-glx2` / `va-driver-all` | VA-API GLX 支持与驱动集合 |
| `vainfo` / `clinfo` | VA-API / OpenCL 检测工具 |

## 四、验证 OpenCL

```bash
clinfo
```

正常情况下应能看到 Intel OpenCL 平台和 GPU 设备：

```
Platform Name    Intel(R) OpenCL Graphics
Device Name      Intel(R) Iris(R) Xe Graphics
Device Version   OpenCL 3.0 NEO
```

能列出 Intel GPU 即说明 OpenCL 运行时安装成功。

## 五、验证 VA-API

```bash
vainfo
```

正常情况下应看到 iHD 驱动加载成功：

```
vainfo: Driver version: Intel iHD driver for Intel(R) Gen Graphics - 24.3.4 ()
```

同时会列出当前硬件支持的视频编解码能力（H.264、HEVC、VP9、AV1 等），不同代际核显支持的 profile 以实际输出为准。

## 六、检查 GPU 设备节点与用户组

确认系统已识别到 DRM 设备：

```bash
ls -l /dev/dri/
# card0  renderD128
```

其中 `renderD128` 是无显示渲染节点，转码、计算和容器场景都会用到它。

确认当前用户是否属于 `render` 和 `video` 用户组：

```bash
groups
```

如果不在，执行以下命令并重新登录（或重启）后生效：

```bash
sudo usermod -aG render,video $USER
```

## 七、可选：补充 Mesa 图形栈

如果还需要完整的桌面图形、Vulkan、OpenGL 能力，可额外安装：

```bash
sudo apt install -y libegl-mesa0 libegl1 libegl-dev libgbm1 libgl1-mesa-dev libgl1-mesa-dri \
  libglapi-mesa libgles-dev libglx-mesa0 libxatracker2 mesa-va-drivers mesa-vdpau-drivers \
  mesa-vulkan-drivers hwinfo
```

对于仅运行 Jellyfin、FFmpeg、推理框架或视频转码任务的服务器来说，这一步通常不是必须的。
