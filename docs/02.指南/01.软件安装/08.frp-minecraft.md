# 使用 frp 进行 Minecraft 联机完整教程

> 推荐使用 frp v0.52.0+ 的 TOML 配置规范。

## 一、准备工作

1. 一台拥有公网 IP 的 Linux 云服务器（作为服务端 `frps`）。
2. 房主的 Windows 电脑（运行 MC 服务端或开放局域网网关，作为客户端 `frpc`）。
3. 前往 [GitHub Releases](https://github.com/fatedier/frp/releases) 下载对应架构的压缩包：
   - Linux 服务端：`frp_x.x.x_linux_amd64.tar.gz`
   - Windows 客户端：`frp_x.x.x_windows_amd64.zip`

---

## 二、Linux 服务端配置 (frps)

### 1. 解压与部署

```bash
tar -zxvf frp_*_linux_amd64.tar.gz
cd frp_*_linux_amd64
```

### 2. 编辑配置文件 `frps.toml`

```toml
# frp 服务监听端口
bindPort = 7000                 
# 身份验证 Token（客户端必须一致）
auth.token = "YourStrongPassword123"
```

### 3. 开放防火墙 / 云服务商安全组

确保放行以下端口：
- **TCP 7000**（frp 通信端口）
- **TCP 25565**（MC 游戏转发端口，如果是基岩版则需放行 **UDP 19132**）

### 4. 启动服务端

- 临时测试：

```bash
./frps -c ./frps.toml
```

- 配置 systemd 后台常驻（推荐）：

创建服务文件 `/etc/systemd/system/frps.service`：

```ini
[Unit]
Description=Frp Server Service
After=network.target

[Service]
Type=simple
User=nobody
Restart=on-failure
RestartSec=5s
ExecStart=/path/to/frps -c /path/to/frps.toml

[Install]
WantedBy=multi-user.target
```

启动并设置开机自启：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now frps
```

## 三、Windows 客户端配置 (frpc)

在房主运行 MC 的电脑上解压 Windows 版 frp。

### 1. 编辑配置文件 `frpc.toml`

根据你的联机场景选择配置：

#### 场景 A：单人存档「对局域网开放」（动态端口）

进入游戏按 `Esc` → 对局域网开放，聊天栏会提示：`本地游戏已在端口 54321 上开启`。

```toml
# 云服务器 IP
serverAddr = "xx.xx.xx.xx"
# frp 服务监听端口
serverPort = 7000
# 身份验证 token (客户端必须一致)
auth.token = "YourStrongPassword123"

[[proxies]]
# 自定义名称
name = "test-tcp"
type = "tcp"
localIP = "127.0.0.1"
# mc 联机时开放的端口
localPort = 25565
# 外部访问端口
remotePort = 25566
```

#### 场景 B：基岩版（Bedrock）

```toml
[[proxies]]
name = "mc-bedrock"
type = "udp"
localIP = "127.0.0.1"
localPort = 19132
remotePort = 19132
```

### 2. 启动客户端

在解压目录下打开 PowerShell / CMD，运行：

```cmd
.\frpc.exe -c .\frpc.toml
```

看到终端输出 `[mc-java] start proxy success` 即表示连接成功。

也可以新建 txt 文件,填入 `.\frpc.exe -c .\frpc.toml` 后保存,再修改文件后缀名为 `bat` 文件,这样以后只需要运行bat文件就能启动用户端服务

---

## 四、好友加入游戏

在 Minecraft 多人游戏列表中添加服务器：

- **服务器地址**：`服务器公网IP:remotePort`
- 如果 `remotePort` 是标准的 `25565`（Java 版），只需直接输入 `服务器公网IP` 即可。

---

## 五、注意事项

1. **正版验证问题**：若提示「无效的会话/无法验证用户名」，任选一种方式关闭正版验证：
   - **方式一（专用服务端）**：在 `server.properties` 中将 `online-mode` 设置为 `false`。
   - **方式二（单人存档）**：安装自定义联机 mod
   
   ![自定义局域网联机.png](https://img.zhaizz.top/file/blog-website/frp-minecraft/自定义局域网联机.png)

   并`在游戏对局域网开放`中把在线模式改为`关闭`

   ![关闭正版验证.png](https://img.zhaizz.top/file/blog-website/frp-minecraft/关闭正版验证.png)
2. **Windows 防火墙**：确保 Windows 防火墙允许了 Java/Minecraft 的入站连接。
3. **断开重连**：如果是局域网开放联机，每次重新开放游戏时端口会随机变动，需要同步修改 `frpc.toml` 的 `localPort` 并重启 `frpc`。
