# Windows11 PowerShell 5.X 升级至 PowerShell 7.X 完整指南

> 参考文章:https://blog.csdn.net/AoXue2017/article/details/158505133

本文整合了将 Windows 11 自带的 PowerShell 5.1 升级至最新 PowerShell 7 版本的方法、版本差异、基础配置及故障处理。

## 升级前的准备：了解现状

在开始升级前，有几个关键背景信息需要了解：

- **版本并存**：PowerShell 7 不会覆盖系统自带的 PowerShell 5.1，二者可 **独立共存**。PowerShell 5.1 的可执行文件名为 `powershell.exe`，而 PowerShell 7 为 `pwsh.exe`
- **升级原因**：PowerShell 5.1 发布于 2016 年，而 PowerShell 7 是持续更新的版本（如 v7.5.x），包含大量新功能和性能改进。打开旧版终端时，通常会有提示信息引导你升级
- **版本查看**：无论在哪个版本中，都可以通过运行 `$PSVersionTable.PSVersion` 命令来查看当前的 PowerShell 版本详情

## 安装 PowerShell 7

主要有两种安装方式，你可以根据偏好选择。

### 方式一：通过 Winget 命令行安装（推荐）

这是最简单快捷的方式，直接在 PowerShell 终端中操作。

1. **搜索可用版本**：

```powershell
winget search Microsoft.PowerShell
```

输出示例：

```
Name               Id                           Version Source
----------------------------------------------------------------
PowerShell         Microsoft.PowerShell         7.5.0.0 winget
PowerShell Preview Microsoft.PowerShell.Preview 7.6.0.2 winget
```

2. **安装特定版本**：

   - **安装稳定版 (Stable)**:

   ```powershell
   winget install --id Microsoft.PowerShell --source winget
   ```

   - **安装预览版 (Preview)**:

   ```powershell
   winget install --id Microsoft.PowerShell.Preview --source winget
   ```

::: info 注意
通过 winget 安装的稳定版 **可能不会** 自动创建快捷方式或修改默认启动配置，而预览版则会配置得更完善。安装完成后，你可能需要手动输入 `pwsh` 来启动新版本。
:::

### 方式二：从 GitHub 下载安装包手动安装

这种方式可以让你选择特定的版本。

1. 访问 PowerShell 官方 GitHub 发布页：[https://github.com/PowerShell/PowerShell/releases](https://github.com/PowerShell/PowerShell/releases)
2. 找到最新的稳定版（例如 `v7.5.1`），在 **Assets** 部分下载适合你操作系统的安装包，例如 `PowerShell-7.5.1-win-x64.exe`
3. 双击下载好的 `.exe` 文件，按照提示完成安装

## 安装后的基本操作

安装完成后，你可以通过以下方式与不同版本交互。

### 手动切换版本

- **启动 PowerShell 5.1**：在终端或运行窗口输入 `powershell`
- **启动 PowerShell 7**：在终端或运行窗口输入 `pwsh`

```powershell
# 输入以下命令启动 PowerShell 7
pwsh

# 启动后再次查看版本，确认已切换
$PSVersionTable.PSVersion
```

### 配置 PowerShell 5.1 自动启动 7

如果你希望在每次打开 PowerShell 5.1 的控制台时，它都 **自动跳转并启动 PowerShell 7**，可以通过修改其配置文件实现。

1. **定位 PowerShell 5.1 的配置文件路径**：

```powershell
# 在任一 PowerShell 中运行
echo $PROFILE
```

此命令通常会返回一个路径，如 `C:\Users\<你的用户名>\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`。注意，PowerShell 5.1 和 7 的配置文件路径是不同的。

2. **检查配置文件是否存在**：

```powershell
Test-Path $PROFILE
```

如果返回 `True`，表示配置文件已存在；如果返回 `False`，表示配置文件不存在，需要创建。

3. **创建或编辑配置文件**：

   - 如果上一步返回 `False`，使用以下命令创建配置文件：

   ```powershell
   New-Item -ItemType File -Path $PROFILE -Force
   ```

   - 使用记事本或 VS Code 等编辑器打开该文件：

   ```powershell
   # 使用记事本打开
   notepad $PROFILE

   # 或使用 VS Code 打开
   code $PROFILE
   ```

4. **添加自动跳转脚本**：

   在配置文件中加入以下逻辑：

```powershell
if ($PSVersionTable.PSVersion.Major -lt 7) {
    pwsh
    exit
}
```

这段代码会检查当前 PowerShell 的主版本号，如果小于 7，则启动 `pwsh` 并退出当前会话。

5. **处理脚本执行策略错误**：

   如果在设置完配置文件后启动 PowerShell 5.1 遇到类似 *"无法加载文件 …，因为在此系统上禁止运行脚本"* 的错误，说明需要修改 PowerShell 的执行策略。

   - **查看当前策略**：

   ```powershell
   Get-ExecutionPolicy -List
   ```

   - **修改当前用户的执行策略**（以管理员身份或当前用户身份运行 PowerShell）：

   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned -Force
   ```

修改后，再次启动 PowerShell 5.1 就会自动进入 PowerShell 7 环境了。

## 配置文件管理

PowerShell 5.1 和 7 使用不同的配置文件，这意味着你可以在不同版本中设置不同的别名、函数和变量。

- **PowerShell 5.1 配置文件**：`C:\Users\<用户名>\Documents\WindowsPowerShell\Microsoft.PowerShell_profile.ps1`
- **PowerShell 7 配置文件**：`C:\Users\<用户名>\Documents\PowerShell\Microsoft.PowerShell_profile.ps1`

你可以通过命令 `Test-Path $PROFILE` 来检查当前会话的配置文件是否存在。如果返回 `False`，可以使用 `New-Item -ItemType File -Path $PROFILE -Force` 创建它，然后用编辑器打开进行编辑。

## 统一终端编码

直接在终端中执行以下命令即可：

```powershell
# Setup-UTF8PowerShellProfile.ps1
$utf8Config = @'
# 设置控制台使用 UTF-8 编码（无 BOM）
chcp 65001 | Out-Null
[Console]::InputEncoding  = [System.Text.UTF8Encoding]::new()
[Console]::OutputEncoding = [System.Text.UTF8Encoding]::new()
$OutputEncoding = [System.Text.UTF8Encoding]::new()
# 设置默认文件操作编码为 UTF-8（无 BOM）
$PSDefaultParameterValues['Out-File:Encoding']    = 'utf8'
$PSDefaultParameterValues['Set-Content:Encoding'] = 'utf8'
$PSDefaultParameterValues['Add-Content:Encoding'] = 'utf8'
'@
# 创建目录（如果不存在）
$profileDir = Split-Path -Parent $PROFILE
if (-not (Test-Path $profileDir)) {
    New-Item -ItemType Directory -Path $profileDir -Force | Out-Null
}
# 读取现有内容
$existing = if (Test-Path $PROFILE) { Get-Content $PROFILE -Raw } else { "" }
# 检查是否已配置（避免重复）
$hasConfig = $existing -match 'Console::OutputEncoding' -and
    $existing -match '\$OutputEncoding' -and
    $existing -match "PSDefaultParameterValues.*Out-File:Encoding"
if (-not $hasConfig) {
    $newContent = if ($existing) { "$existing`r`n$utf8Config" } else { $utf8Config }
    $utf8NoBom = New-Object System.Text.UTF8Encoding($false)  # $false = 无 BOM
    [System.IO.File]::WriteAllText($PROFILE, $newContent, $utf8NoBom)
    Write-Host "✅ UTF-8 配置已写入 Profile！路径: $PROFILE" -ForegroundColor Green
} else {
    Write-Host "ℹ️ UTF-8 已配置，跳过。" -ForegroundColor Cyan
}
```

上述执行完后，再执行以下命令，立即生效：

```powershell
. $PROFILE
```

## 后续更新

终端直接执行以下命令即可：

```powershell
winget upgrade --id Microsoft.PowerShell --silent
```
