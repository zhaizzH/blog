# VS Code 控制台中文乱码解决方案

在中文版 Windows 上使用 VS Code 运行 Spring Boot 项目时，控制台经常出现中文乱码。明明代码里是 `业务异常`，终端却显示成 `涓氬姟寮傚父`。本文分析乱码产生的根本原因，并给出一次性解决的方案。

## 问题现象

启动 Spring Boot 应用后，控制台日志的中文全部变成乱码：

```
2026-08-05T14:39:53.471+08:00  WARN 17152 --- [animetracker-business] [nio-8080-exec-4] GlobalExceptionHandler   : 涓氬姟寮傚父: code=401, message=鐢ㄦ埛鍚嶆垨瀵嗙爜閿欒
```

> 这行日志实际想表达的是：`业务异常: code=401, message=用户名或密码错误`

| 场景 | 显示结果 |
|------|---------|
| 期望 | `业务异常: code=401, message=用户名或密码错误` |
| 实际 | `涓氬姟寮傚父: code=401, message=鐢ㄦ埛鍚嶆垨瀵嗙爜閿欒` |

### 为什么会错位

- **Java 侧**：JDK 18 起（JEP 400）`file.encoding` 默认就是 UTF-8，本项目用的 Java 21 更是如此，日志以 UTF-8 字节输出到标准输出。
- **控制台侧**：中文版 Windows 控制台默认代码页是 GBK（936），VS Code 集成终端继承系统代码页。

一侧输出 UTF-8，一侧按 GBK 解读，乱码随之而来。

## 解决方案

### 1. 终端代码页切换为 UTF-8

在终端执行 `chcp 65001` 可将当前控制台代码页切换为 UTF-8。但手动每次执行太麻烦，可以在 VS Code 的**用户设置**（`settings.json`）中配置终端 profile，让每个新终端自动执行：

```json
"terminal.integrated.profiles.windows": {
  "PowerShell": {
    "source": "PowerShell",
    "icon": "terminal-powershell",
    "args": ["-NoExit", "-Command", "chcp 65001"]
  },
  "Command Prompt": {
    "path": ["${env:windir}\\Sysnative\\cmd.exe", "${env:windir}\\System32\\cmd.exe"],
    "args": ["/k", "chcp 65001"],
    "icon": "terminal-cmd"
  },
  "Git Bash": {
    "source": "Git Bash",
    "icon": "terminal-git-bash"
  }
}
```

> Git Bash 基于 mintty，原生支持 UTF-8，无需额外配置。

### 2. 删除废弃的 shellArgs 配置

早期教程会推荐在 `settings.json` 里写 `terminal.integrated.shellArgs.windows`：

```json
// 无效配置：VS Code 1.58 起已废弃，新版本直接忽略
"terminal.integrated.shellArgs.windows": ["-NoExit", "/c", "chcp 65001"]
```

该配置在 VS Code 1.58（2021 年）就被废弃，新版本中**不会生效**。如果你按旧教程配过，乱码没解决很可能就是这个原因，请删掉它，改用上面的 profile 方式。

### 3. Spring Boot 调试输出改走集成终端

如果通过 F5 启动 Spring Boot（`launch.json` 中 `type: java`），默认输出到内置 **Debug Console**。这个控制台在中文系统上按系统语言解码，`chcp 65001` 对它的输出无效。

解决办法是在 `launch.json` 的 Java 配置中显式指定输出到集成终端：

```json
{
  "type": "java",
  "name": "SpringBoot 后端",
  "request": "launch",
  "mainClass": "top.zhaizz.app.AppApplication",
  "projectName": "animetracker-app",
  "console": "integratedTerminal"
}
```

这样日志走集成终端，配合第 1 步的 `chcp 65001`，即可正常显示中文。

### 4. 重启终端生效

`chcp` 只对**新建的进程**生效。修改配置后需要：

1. 关闭所有已打开的终端标签页
2. 重启 VS Code（确保配置重新加载）
3. 重新运行 Spring Boot

## 验证

重新启动应用，再次触发登录失败日志，控制台应显示：

```
2026-08-05T14:39:53.471+08:00  WARN 17152 --- [animetracker-business] [nio-8080-exec-4] GlobalExceptionHandler   : 业务异常: code=401, message=用户名或密码错误
```
