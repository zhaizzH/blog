# Windows 下 Node.js / npm 全局包与缓存路径修改及环境变量配置

默认情况下，在 Windows 上使用 `npm install -g <package>` 安装的全局包以及缓存文件会被存放在系统的 C 盘用户目录下（如 `C:\Users\<username>\AppData\Roaming\npm` 和 `npm-cache`）。

## 1. 查看当前 npm 配置路径

在修改之前，可以通过以下命令查看 npm 当前的全局路径与缓存路径配置：

```bash
npm config ls -l
```

执行后会列出 npm 的所有配置项，重点关注以下两个关键属性：
- `prefix`：npm 全局安装包及对应 CLI 执行脚本的存放路径。
- `cache`：npm 下载模块时的缓存数据存放路径。

也可以直接通过 `get` 命令精准查看：

```bash
npm config get prefix
npm config get cache
```

---

## 2. 创建自定义目录并修改路径

### 2.1 创建目录

选择合适的磁盘分区（例如 `C:\software\env\nodejs\repository\` 或其他盘符），手动新建两个文件夹：
- `global`：用于存放全局模块与命令脚本
- `cache`：用于存放缓存数据

### 2.2 修改 npm 配置

在终端中执行 `npm config set` 命令进行路径重定向（请根据实际路径替换）：

```bash
npm config set prefix "C:\software\env\nodejs\repository\global"
npm config set cache "C:\software\env\nodejs\repository\cache"
```

::: tip 提示
执行上述命令后，配置会自动写入用户主目录下的 `.npmrc` 文件中（如 `C:\Users\<username>\.npmrc`）。
:::

## 3. 配置系统环境变量

路径修改后，为了让全局安装的 CLI 工具（如 `yarn`、`pnpm`、`rimraf`、`vue` 等）能够在任何命令行中直接调用，且 Node.js 程序能正确加载全局模块，需要配置环境变量。

### 3.1 添加用户变量 `NODE_PATH`

1. 按 `Win + S` 搜索并打开 **“编辑系统环境变量”**，点击 **“环境变量”**。
2. 在 **“用户变量”**（或系统变量）区域点击 **新建**：
   - **变量名**：`NODE_PATH`
   - **变量值**：`C:\software\env\nodejs\repository\global\node_modules`
3. 点击 **确定** 保存。

### 3.2 更新系统/用户变量 `Path`

1. 在 **“系统变量”**（或“用户变量”）中找到并选中 `Path`，点击 **编辑**。
2. 点击 **新建**，添加自定义的全局工具可执行文件目录：
   - 路径：`C:\software\env\nodejs\repository\global`
3. （可选）如果列表中存在默认的旧路径（如 `C:\Users\<username>\AppData\Roaming\npm`），建议删除或将其下移，避免路径优先级冲突。
4. 依次点击 **确定** 保存所有窗口。

---

## 4. 验证配置是否生效

配置完成后，**重新打开一个新的终端窗口**（PowerShell 或 CMD），进行验证。

### 4.1 检查 npm 配置

运行 `npm config ls` 查看当前的生效配置：

```bash
npm config ls
```

输出示例：

```ini
; "builtin" config from C:\software\env\nodejs\node_modules\npm\npmrc

; prefix = "C:\\Users\\zzz\\AppData\\Roaming\\npm" ; overridden by user

; "user" config from C:\Users\zzz\.npmrc

cache = "C:\\software\\env\\nodejs\\repository\\cache"
prefix = "C:\\software\\env\\nodejs\\repository\\global"

; node bin location = C:\software\env\nodejs\node.exe
; node version = v24.18.0
; npm local prefix = C:\Windows\System32
; npm version = 11.16.0
; cwd = C:\Windows\System32
; HOME = C:\Users\zzz
; Run `npm config ls -l` to show all defaults.
```

### 4.2 全局安装测试

尝试全局安装一个轻量 CLI 工具测试环境变量是否连通：

```bash
npm install -g rimraf
```

安装完成后执行：

```bash
rimraf --version
```

若能正常输出版本号，说明 npm 全局路径与环境变量配置成功。
